1. 双線形写像

次を満たす写像𝑓:ℝ𝑛×ℝ𝑛→𝑉を双線形写像という。

  1. ∀𝑎,𝑏,𝑐∈ℝ𝑛:𝑓(𝑎+𝑏,𝑐)=𝑓(𝑎,𝑐)+𝑓(𝑏,𝑐)
  2. ∀𝑎,𝑏,𝑐∈ℝ𝑛:𝑓(𝑎,𝑏+𝑐)=𝑓(𝑎,𝑏)+𝑓(𝑎,𝑐)
  3. ∀𝑎,𝑏∈ℝ𝑛,∀𝜆∈ℝ:𝑓(𝜆𝑎,𝑏)=𝑓(𝑎,𝜆𝑏)=𝜆𝑓(𝑎,𝑏)

2. 内積

𝑎∈ℝ𝑛と𝑏∈ℝ𝑛の内積ℝ𝑛×ℝ𝑛→ℝを次で定義する。

⟨ 𝑎 , 𝑏 ⟩ = ∑ 𝑖 = 0 𝑛 − 1 𝑎 𝑖 𝑏 𝑖

これは双線形写像として扱うことができる。しかし一般に、双線形写像の条件を満たすような写像𝑓:ℝ𝑛×ℝ𝑛→ℝ𝑛×ℝ𝑛は存在しない。 なぜならば、そのような写像𝑓があるならば

𝑓 ( 0 , 𝑎 ) = 𝑓 ( 0 + 0 , 𝑎 ) = 𝑓 ( 0 , 𝑎 ) + 𝑓 ( 0 , 𝑎 )

より、𝑓(0,𝑎)=0でなければならず、同様に𝑎≠𝑏たる𝑏をとっても、𝑓(0,𝑏)=0となり矛盾する。

そこで、ℝ𝑛×ℝ𝑛上ではなく、新たな線形空間ℝ𝑛⊗ℝ𝑛への双線形写像を考える。

3. Tensor積

今、ℝ𝑛の標準基底ℰ︀={𝑒0,𝑒1,…,𝑒𝑛−1}について、形式的な記号⊗により{𝑒𝑖⊗𝑒𝑗}を基底とする線形空間をℝ𝑛⊗ℝ𝑛={∑𝑖,𝑗𝜆𝑖,𝑗(𝑒𝑖⊗𝑒𝑗)|𝜆𝑖,𝑗∈ℝ}とする。

いま、演算⊗:ℝ𝑛×ℝ𝑛→ℝ𝑛⊗ℝ𝑛を次で定義する。

( ∑ 𝑖 𝜆 𝑖 𝑒 𝑖 ) ⊗ ( ∑ 𝑗 𝜇 𝑗 𝑒 𝑗 ) = ∑ 𝑖 , 𝑗 𝜆 𝑖 𝜇 𝑗 ( 𝑒 𝑖 ⊗ 𝑒 𝑗 )

ここで演算⊗はTensor積といわれる。 ここでTensor積は双線形写像である。

さらに、例えばℝ𝑛上の内積ℝ𝑛×ℝ𝑛⟶ℝについて、写像𝑓:ℝ𝑛⊗ℝ𝑛→ℝを任意の標準基底𝑒𝑖、𝑒𝑗に対して

𝑓 ( 𝑒 𝑖 ⊗ 𝑒 𝑗 ) = ⟨ 𝑒 𝑖 , 𝑒 𝑗 ⟩

を満たす線形写像として定めると、任意の𝑎,𝑏∈ℝ𝑛に対して

𝑓 ( 𝑎 ⊗ 𝑏 ) = ⟨ 𝑎 , 𝑏 ⟩

が成り立ち、しかも𝑓は一意的である（ことが示される）。

とくに具体的な計算を行うと

⟨ ( 𝑎 0 ⋮ 𝑎 𝑛 − 1 ) , ( 𝑏 0 ⋮ 𝑏 𝑛 − 1 ) ⟩ = ∑ 𝑖 = 0 𝑛 − 1 𝑎 𝑖 𝑏 𝑖

であるから、ℝ𝑛の標準基底について

𝑓 ( 𝑒 𝑖 ⊗ 𝑒 𝑗 ) = 𝛿 𝑖 , 𝑗

が示される。ゆえに線形写像𝑓は

𝑓 ( ∑ 𝑖 , 𝑗 𝜆 𝑖 , 𝑗 ( 𝑒 𝑖 ⊗ 𝑒 𝑗 ) ) = ∑ 𝑖 , 𝑗 𝜆 𝑖 , 𝑗 𝛿 𝑖 , 𝑗 = ∑ 𝑖 𝜆 𝑖 , 𝑖 = tr ( 𝜆 𝑖 , 𝑗 )

であることがわかる。

4. 商空間

ある全射たる線形写像𝑝:𝑉→𝑉′と始域の部分空間𝑊⊆𝑉が与えられたとき、Ker𝑝={𝑥∈𝑉|𝑝(𝑥)=0}=𝑊となるように空間𝑉′をとることができ、しかもその取り方は一意的である。この線形空間𝑉′を商空間𝑉/𝑊という。

5. 外冪と行列式

ℝ𝑛におけるTensor積空間

𝔓 𝑟 ≔ ⟨ 𝑎 0 ⊗ ⋯ ⊗ 𝑎 𝑟 − 1 | 𝑎 0 , … , 𝑎 𝑟 − 1 ∈ ℝ 𝑛 ⟩

について、その部分（線形）空間

ℜ 𝑟 ≔ ⟨ 𝑎 0 ⊗ ⋯ ⊗ 𝑎 𝑖 ⊗ ⋯ ⊗ 𝑎 𝑗 ⊗ ⋯ ⊗ 𝑎 𝑟 − 1 | 𝑎 0 , … , 𝑎 𝑟 − 1 ∈ ℝ 𝑛 ; 𝑖 ≠ 𝑗 ∧ 𝑎 𝑖 = 𝑎 𝑗 ⟩ ⊆ 𝔓 𝑟

による商空間𝔓𝑟/ℜ𝑟を、ℝ𝑛の𝑟次外冪といって、Λ𝑟ℝ𝑛と表す。

ここで𝑎0⊗⋯⊗𝑎𝑟−1の像を𝑎0∧⋯∧𝑎𝑟−1と書き表す。

いま、𝑛=𝑟=2として考えると、

𝑥 ⊗ 𝑥 ∈ ℜ 2 ∴ 𝑥 ∧ 𝑥 = 0
[1]

であり、式 [1]において𝑥=𝑒0+𝑒1とすることで

( 𝑒 0 + 𝑒 1 ) ∧ ( 𝑒 0 + 𝑒 1 ) = 𝑒 0 ∧ 𝑒 0 + 𝑒 0 ∧ 𝑒 1 + 𝑒 1 ∧ 𝑒 0 + 𝑒 1 ∧ 𝑒 1 = 0

が得られる。同時に式 [1]において𝑥=𝑒0あるいは𝑥=𝑒1とすることで得られる

𝑒 0 ∧ 𝑒 0 = 𝑒 1 ∧ 𝑒 1 = 0

を利用して

𝑒 0 ∧ 𝑒 1 = − 𝑒 1 ∧ 𝑒 0

を得る。ゆえに一般のℝ2上の元𝑎𝑒0+𝑐𝑒1および𝑏𝑒0+𝑑𝑒1について

( 𝑎 𝑒 0 + 𝑐 𝑒 1 ) ∧ ( 𝑏 𝑒 0 + 𝑑 𝑒 1 ) = 𝑎 𝑏 ( 𝑒 0 ∧ 𝑒 0 ) + 𝑎 𝑑 ( 𝑒 0 ∧ 𝑒 1 ) + 𝑐 𝑏 ( 𝑒 1 ∧ 𝑒 0 ) + 𝑐 𝑑 ( 𝑒 1 ∧ 𝑒 1 ) = 𝑎 𝑏 0 + 𝑎 𝑑 ( 𝑒 0 ∧ 𝑒 1 ) + 𝑐 𝑏 ( − 𝑒 0 ∧ 𝑒 1 ) + 𝑐 𝑑 0 = ( 𝑎 𝑑 − 𝑏 𝑐 ) ( 𝑒 0 ∧ 𝑒 1 )
[2]

と計算できることがわかる。

一般に、dimΛ𝑛ℝ𝑛=1であることが知られており、しかもその基底は𝑒0∧⋯∧𝑒𝑛−1である。ゆえに𝑎0,…,𝑎𝑛−1に対して、ある実数det(𝑎0,…,𝑎𝑛−1)∈ℝが存在して

det ( 𝑎 0 , … , 𝑎 𝑛 − 1 ) = 𝑎 0 ∧ ⋯ ∧ 𝑎 𝑛 − 1 𝑒 0 ∧ ⋯ ∧ 𝑒 𝑛 − 1

とかける。これを行列(𝑎0,…,𝑎𝑛−1)の行列式という。

例えば、式 [2]によれば

det ( 𝑎 𝑏 𝑐 𝑑 ) = 𝑎 𝑑 − 𝑏 𝑐

である。
