1. 超幾何分布

母比率𝑝=𝑀𝑁の有限母集団から𝑛個の標本を非復元抽出することを考える。

いま、二項係数を次のとおり拡張する。

( 𝑛 𝑘 ) = { 𝑛 ! 𝑘 ! ( 𝑛 − 𝑘 ) ! ( 𝑘 = 0 , 1 , … , 𝑛 ) 0 ( otherwise )

いま、標本のうち性質を満たすものの個数を𝑘とすると、場合の数は

( 𝑀 𝑘 ) ⋅ ( 𝑁 − 𝑀 𝑛 − 𝑘 )

であり、ゆえに

( 𝑁 𝑛 ) = ∑ 𝑘 = 0 𝑛 [ ( 𝑀 𝑘 ) ⋅ ( 𝑁 − 𝑀 𝑛 − 𝑘 ) ]

がいえる。

しかも𝑘を確率変数とみなすと、𝑘は分布

Pr { 𝑋 = 𝑘 } = ( 𝑀 𝑘 ) ⋅ ( 𝑁 − 𝑀 𝑛 − 𝑘 ) ( 𝑁 𝑛 ) ( 𝑘 ∈ 0 , 1 , … , 𝑛 )

に従う。 この分布は超幾何分布と呼ばれる。以降Hyper(𝑁,𝑀,𝑛)で表す。

二項分布は復元抽出であったことに注意せよ。

2. 有限母集団補正

超幾何分布に従う確率変数𝑋∼Hyper(𝑁,𝑀,𝑛)の期待値は

𝔼 [ 𝑋 ] = 1 ( 𝑁 𝑛 ) ∑ 𝑘 = 0 𝑛 [ 𝑘 ( 𝑀 𝑘 ) ⋅ ( 𝑁 − 𝑀 𝑛 − 𝑘 ) ] = 1 ( 𝑁 𝑛 ) ∑ 𝑘 = 0 𝑛 [ 𝑀 ( 𝑀 − 1 𝑘 − 1 ) ⋅ ( 𝑁 − 𝑀 ( 𝑛 − 1 ) − ( 𝑘 − 1 ) ) ] = 1 ( 𝑁 𝑛 ) 𝑀 ∑ 𝑘 ′ = 0 𝑛 − 1 [ ( 𝑀 − 1 𝑘 ′ ) ⋅ ( ( 𝑁 − 1 ) − ( 𝑀 − 1 ) ( 𝑛 − 1 ) − 𝑘 ′ ) ] = ( 𝑁 − 1 𝑛 − 1 ) ( 𝑁 𝑛 ) 𝑀 = 𝑛 𝑁 𝑀 = 𝑛 𝑀 𝑁 = 𝑛 𝑝

と二項分布の結果に一致する。

一方で分散は二項分布の結果と一致しない。 これを示そう。

ところで、任意の確率変数𝑋について

Var ( 𝑋 ) = 𝔼 [ 𝑋 ( 𝑋 − 1 ) ] + 𝔼 [ 𝑋 ] − ( 𝔼 [ 𝑋 ] ) 2

であることが知られている。 ここで𝔼[𝑋(𝑋−1)]は分散モーメントと呼ばれる。

いま、𝑋∼Hyper(𝑁,𝑀,𝑛)について

𝔼 [ 𝑋 ( 𝑋 − 1 ) ] = 1 ( 𝑁 𝑛 ) ∑ 𝑘 = 0 𝑛 [ 𝑘 ( 𝑘 − 1 ) ( 𝑀 𝑘 ) ⋅ ( 𝑁 − 𝑀 𝑛 − 𝑘 ) ] = 1 ( 𝑁 𝑛 ) ∑ 𝑘 = 0 𝑛 [ 𝑀 ( 𝑀 − 1 ) ( 𝑀 − 2 𝑘 − 2 ) ⋅ ( ( 𝑁 − 2 ) − ( 𝑀 − 2 ) ( 𝑛 − 2 ) − ( 𝑘 − 2 ) ) ] = 1 ( 𝑁 𝑛 ) 𝑀 ( 𝑀 − 1 ) ∑ 𝑘 ′ = 0 𝑛 − 2 [ ( 𝑀 − 2 𝑘 ′ ) ⋅ ( ( 𝑁 − 2 ) − ( 𝑀 − 2 ) ( 𝑛 − 2 ) − 𝑘 ′ ) ] = ( 𝑁 − 2 𝑛 − 2 ) ( 𝑁 𝑛 ) 𝑀 ( 𝑀 − 1 ) = 𝑛 ( 𝑛 − 1 ) 𝑁 ( 𝑁 − 1 ) 𝑀 ( 𝑀 − 1 )

であるから、その分散は

Var ( 𝑋 ) = 𝑛 ( 𝑛 − 1 ) 𝑀 ( 𝑀 − 1 ) 𝑁 ( 𝑁 − 1 ) + 𝑛 𝑀 𝑁 − 𝑛 2 𝑀 2 𝑁 2 = 𝑛 𝑀 𝑁 [ ( 𝑛 − 1 ) ( 𝑀 − 1 ) 𝑁 − 1 + 1 − 𝑛 𝑀 𝑁 ] = 𝑛 𝑀 𝑁 ⋅ ( 𝑛 𝑀 − 𝑛 − 𝑀 + 𝑁 ) 𝑁 − 𝑛 𝑀 ( 𝑁 − 1 ) 𝑁 ( 𝑁 − 1 ) = 𝑛 𝑀 𝑁 ⋅ − 𝑛 𝑁 − 𝑀 𝑁 + 𝑁 2 + 𝑛 𝑀 𝑁 ( 𝑁 − 1 ) = 𝑛 𝑀 𝑁 ⋅ ( 𝑁 − 𝑀 ) ( 𝑁 − 𝑛 ) 𝑁 ( 𝑁 − 1 ) = 𝑛 𝑀 𝑁 ( 1 − 𝑀 𝑁 ) × 𝑁 − 𝑛 𝑁 − 1 = 𝑛 𝑝 ( 1 − 𝑝 ) × 𝑁 − 𝑛 𝑁 − 1

となり、二項分布の結果𝑛𝑝(1−𝑝)に補正係数𝑁−𝑛𝑁−1が乗じられてしまう。

このように、超幾何分布を二項分布により近似するとき、（厳密には）分散に補正係数

𝑁 − 𝑛 𝑁 − 1

を乗じなければならず、これを有限母集団補正という。

3. 補正係数

𝑁−1≈𝑁として抽出率𝑓=𝑛𝑁と補正係数の関係を調べると

𝑁 − 𝑛 𝑁 − 1 ≈ 𝑁 − 𝑛 𝑁 = 1 − 𝑛 𝑁 = 1 − 𝑓

となり、例えば相対誤差が𝑓1−𝑓=5%となる点は𝑓≈4.76%であるとわかる。

よっておよそ𝑓≥5%のときは有限母集団補正を考慮する必要があり、実際の運用でもこれを目安とすることが多い。
