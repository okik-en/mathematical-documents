1. 線形単回帰

相関とは、2変量(𝑥,𝑦)の間の間にある関係のことを指す。 相関に対して、説明変数𝑥から目的変数𝑦の予測を目指すことを単回帰という。

例えば一次関数による単回帰を考える。目的変数𝑦が説明変数𝑥の一次関数であると主張したいものとする。

𝑦 𝑖 ̂ = 𝛼 𝑥 𝑖 + 𝛽

しかしこのとき、実際には誤差𝛿が発生し、これを残差と呼ぶ。

𝑦 𝑖 = 𝛼 𝑥 𝑖 + 𝛽 + 𝛿 𝑖 ( = 𝑦 𝑖 ̂ + 𝛿 𝑖 )

よりよい説明のためには、残差が最小であることが望ましい。その基準として残差の分散𝜎𝛿2を最小化することが考えられる。

𝜎 𝛿 2 = 1 𝑛 ∑ 𝑖 𝛿 𝑖 2 = 1 𝑛 ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 𝑖 ̂ ) 2 = 1 𝑛 ∑ 𝑖 ( 𝛼 𝑥 𝑖 + 𝛽 − 𝑦 𝑖 ) 2

これを最小二乗法またはLSM(Least Squares Method)という。 （注：厳密には、残差の分散ではなく残差平方和∑𝑖𝛿𝑖2を最小化するものであるが、標本数𝑛を固定した場合これらは同一視できる。）

2. 最小二乗法

2.1. 正規方程式

残差の分散を𝛼および𝛽について整理すると

𝜎 𝛿 2 = 1 𝑛 ∑ 𝑖 ( 𝑥 𝑖 𝛼 + 𝛽 − 𝑦 𝑖 ) 2 = 1 𝑛 ∑ 𝑖 ( 𝑥 𝑖 2 𝛼 2 + 2 𝑥 𝑖 𝛼 𝛽 + 𝛽 2 − 2 𝑥 𝑖 𝑦 𝑖 𝛼 − 2 𝑦 𝑖 𝛽 + 𝑦 𝑖 2 ) = ( 1 𝑛 ∑ 𝑖 𝑥 𝑖 2 ) 𝛼 2 + 2 ( 1 𝑛 ∑ 𝑖 𝑥 𝑖 ) 𝛼 𝛽 + 𝛽 2 − 2 ( 1 𝑛 ∑ 𝑖 𝑥 𝑖 𝑦 𝑖 ) 𝛼 − 2 ( 1 𝑛 ∑ 𝑖 𝑦 𝑖 ) 𝛽 + ( 1 𝑛 ∑ 𝑖 𝑦 𝑖 2 ) = ( 𝜎 𝑥 2 + ( 𝑥 ) 2 ) 𝛼 2 + 2 𝑥 𝛼 𝛽 + 𝛽 2 − 2 ( 𝜎 𝑥 𝑦 + 𝑥 𝑦 ) 𝛼 − 2 𝑦 𝛽 + 𝜎 𝑦 2 + ( 𝑦 ) 2

となる。

ここで𝛼と𝛽を変数とみれば、𝜎𝛿2は二次式であり、しかも𝛼2および𝛽2の係数は正であるため、𝜎𝛿2は凸関数である。

すなわち𝜎𝛿2は

𝜕 𝜕 𝛼 𝜎 𝛿 2 = 𝜕 𝜕 𝛽 𝜎 𝛿 2 = 0
[1]

たる点で最小値をとる。これをしばしば正規方程式という。

𝛼による偏微分

𝛼による偏微分を行うと

𝜕 𝜕 𝛼 𝜎 𝛿 2 = 2 ( 𝜎 𝑥 2 + ( 𝑥 ) 2 ) 𝛼 + 2 𝑥 𝛽 − 2 ( 𝜎 𝑥 𝑦 + 𝑥 𝑦 )

となり、式 [1]によれば最良の回帰𝑦𝑖̂=𝛼̂𝑥𝑖+𝛽̂は

( 𝜎 𝑥 2 + ( 𝑥 ) 2 ) 𝛼 ̂ + 𝑥 𝛽 ̂ = 𝜎 𝑥 𝑦 + 𝑥 𝑦
[2]

を満たす。

𝛽による偏微分

𝛽による偏微分を行うと

𝜕 𝜕 𝛽 𝜎 𝛿 2 = 2 𝑥 𝛼 + 2 𝛽 − 2 𝑦

となり、式 [1]によれば最良の回帰𝑦𝑖̂=𝛼̂𝑥𝑖+𝛽̂は

𝑥 𝛼 ̂ + 𝛽 ̂ = 𝑦
[3]

を満たす。

いま、式 [2]−𝑥×式 [3] を行うことで

𝑥 𝜎 𝑥 2 𝛼 ̂ = 𝑥 𝜎 𝑥 𝑦 ⟺ 𝛼 ̂ = 𝜎 𝑥 𝑦 𝜎 𝑥 2

であり、また式 [3]に代入することで

𝛽 ̂ = 𝑦 − 𝑥 𝛼 ̂ = 𝑦 − 𝜎 𝑥 𝑦 𝜎 𝑥 2 𝑥

がいえる。

ゆえに最良の回帰直線は

𝑦 𝑖 ̂ = 𝜎 𝑥 𝑦 𝜎 𝑥 2 ( 𝑥 𝑖 − 𝑥 ) + 𝑦
[4]

となる。あるいは相関係数𝜌𝑥𝑦を用いて

𝑦 𝑖 ̂ − 𝑦 𝜎 𝑦 = 𝜌 𝑥 𝑦 𝑥 𝑖 − 𝑥 𝜎 𝑥
[5]

ともかける。

2.2. 回帰の現象

いま、説明変数𝑥と応答変数𝑦が同一の分布に従っているものとする。

とくに𝑥=𝑦=𝜇とすれば、式 [5]の両辺に𝜎𝑥=𝜎𝑦=𝜎をかけることにより

| 𝑦 𝑖 ̂ − 𝜇 | = | 𝜌 𝑥 𝑦 | | 𝑥 𝑖 − 𝜇 | ≤ | 𝑥 𝑖 − 𝜇 |

が得られ、|𝜌𝑥𝑦|≠1のとき応答変数は説明変数より平均に近づく性質があるとわかる。

これを回帰の現象あるいは平均への回帰という。

平均への回帰を誤って解釈してしまうことを回帰の過誤という。例えば、「昨日行ったテストは平均点を下回っていた。そこで勉強するように注意したところ、今回は平均点に近づいた。これはその注意によるものである。」など。

2.3. 回帰直線の性質

  1. 式 [3]より、予測値𝑦𝑖̂の平均は観測値𝑦𝑖の平均と等しい
  2. すなわち、残差𝛿𝑖の平均は0となる
  3. 式 [5]より、回帰直線は点(𝑥,𝑦)を通る
  4. 予測値 𝑦 𝑖 ̂ と残差 𝛿 𝑖 の相関係数は 0 である
    ∵ 𝜌 𝑦 ̂ 𝛿 = 1 𝑛 ∑ 𝑖 ( 𝑦 𝑖 ̂ − 𝑦 ) ( 𝛿 𝑖 − 0 ) = 𝛼 ̂ 𝑛 ( 𝑥 𝑖 − 𝑥 ) ( 𝑦 𝑖 − 𝑦 − 𝛼 ̂ ( 𝑥 𝑖 − 𝑥 ) ) = 𝛼 ̂ 𝑛 ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) ( 𝑦 𝑖 − 𝑦 ) − 𝛼 ̂ 2 𝑛 ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) 2 = 𝛼 ̂ 𝜎 𝑥 𝑦 − 𝛼 ̂ 2 𝜎 𝑥 2 = 𝛼 ̂ 𝜎 𝑥 𝑦 − 𝛼 ̂ 𝜎 𝑥 𝑦 = 0
    [6]

    ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 = ∑ 𝑖 [ ( 𝑦 𝑖 ̂ − 𝑦 ) + ( 𝑦 𝑖 − 𝑦 𝑖 ̂ ) ] 2 = ∑ 𝑖 [ ( 𝑦 𝑖 ̂ − 𝑦 ) + 𝛿 𝑖 ] 2 = ∑ 𝑖 ( 𝑦 𝑖 ̂ − 𝑦 ) 2 ⎵ 回帰による平方和 + ∑ 𝑖 𝛿 𝑖 2 ⎵ 残差平方和 ( ∵ 式 [6] )
    [7]

2.4. 決定係数

応答変数の偏差平方和を、回帰による平方和と残差平方和に分解したとき、その比率を決定係数あるいは寄与率という。式 [5]より決定係数は

∑ 𝑖 ( 𝑦 𝑖 ̂ − 𝑦 ) 2 ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 = 𝜌 𝑥 𝑦 2 𝜎 𝑦 2 ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) 2 𝜎 𝑥 2 ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 = 𝜌 𝑥 𝑦 2 𝜎 𝑦 2 𝜎 𝑥 2 𝜎 𝑥 2 𝜎 𝑦 2 = 𝜌 𝑥 𝑦 2
[8]

とかけて、すなわち決定係数は相関係数の2乗である。

とくに式 [8]より式 [7]を変形すると

∑ 𝑖 𝛿 𝑖 2 = ( 1 − 𝜌 𝑥 𝑦 2 ) ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2

とかけて、とくに𝜌𝑥𝑦2=1のときは∑𝑖𝛿𝑖2=0となって、すべての観測値は回帰直線によって完全に決定されることが読み取れる。

3. 擬相関

有名な例を挙げよう。一般に、アイスクリームへの支出が増えると水難事故も増えることが知られている。しかし、これはアイスクリームが水難事故を引き起こしているのではなく、夏になって気温が上昇することでアイスクリームへの支出が増えると同時に海や川での水難事故が増えることによる。 このように、ある変量𝑥と𝑦との間に認められる相関関係が、第三の変量𝑧によるものであるとき、これを見かけの相関、あるいは擬相関と呼ぶ。

例えば、アメリカのあるスーパーにおけるビールの売り上げと赤ちゃん用おむつの売り上げには相関が見つかったという。一体なぜだろうか？（もちろん、アメリカの赤ちゃんがビールを嗜む、というわけではない。）

3.1. 偏相関係数

いま、3つの変量𝑥、𝑦、𝑧があり、𝑥と𝑦の相関係数を求めたいとする。しかし𝑥と𝑦の間には変量𝑧の影響があり、それが本当に𝑥と𝑦の相関を反映しているとは限らない（見かけの相関）。そこでその影響が𝑧による回帰式

𝑥 𝑖 ̂ = 𝑎 𝑧 𝑖 + 𝑏 , 𝑦 𝑖 ̂ = 𝑐 𝑧 𝑖 + 𝑑

で説明できるものと仮定し、その影響を除いた変量

𝑥 𝑖 ′ ≔ 𝑥 𝑖 − 𝑥 𝑖 ̂ , 𝑦 𝑖 ′ ≔ 𝑦 𝑖 − 𝑦 𝑖 ̂

による相関係数𝜌𝑥′𝑦′を考える。これを偏相関係数といって𝜌𝑥𝑦∙𝑧と表すものとする。

式 [4]と同様にして

𝑥 𝑖 ′ = 𝑥 𝑖 − 𝑥 − 𝜎 𝑥 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) , 𝑦 𝑖 ′ = 𝑦 𝑖 − 𝑦 − 𝜎 𝑦 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 )

により、𝑥′=𝑦′=0に注意して

𝜎 𝑥 ′ 2 = 1 𝑛 ∑ 𝑖 𝑥 𝑖 ′ 2 = 1 𝑛 ∑ 𝑖 [ ( 𝑥 𝑖 − 𝑥 ) − 𝜎 𝑥 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] 2 = 𝜎 𝑥 2 − 𝜎 𝑥 𝑧 2 𝜎 𝑧 2 = 𝜎 𝑥 2 ( 1 − 𝜌 𝑥 𝑧 2 ) 𝜎 𝑦 ′ 2 = 1 𝑛 ∑ 𝑖 𝑦 𝑖 ′ 2 = 1 𝑛 ∑ 𝑖 [ ( 𝑦 𝑖 − 𝑦 ) − 𝜎 𝑦 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] 2 = 𝜎 𝑦 2 − 𝜎 𝑦 𝑧 2 𝜎 𝑧 2 = 𝜎 𝑦 2 ( 1 − 𝜌 𝑦 𝑧 2 ) 𝜎 𝑥 ′ 𝑦 ′ = 1 𝑛 ∑ 𝑖 𝑥 𝑖 ′ 𝑦 𝑖 ′ = 1 𝑛 ∑ 𝑖 [ ( 𝑥 𝑖 − 𝑥 ) − 𝜎 𝑥 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] [ ( 𝑦 𝑖 − 𝑦 ) − 𝜎 𝑦 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] = 𝜎 𝑥 𝑦 − 𝜎 𝑥 𝑧 𝜎 𝑦 𝑧 𝜎 𝑧 2 = 𝜎 𝑥 𝜎 𝑦 ( 𝜌 𝑥 𝑦 − 𝜌 𝑥 𝑧 𝜌 𝑦 𝑧 )

であるから、偏相関係数は

𝜌 𝑥 𝑦 ∙ 𝑧 = 𝜎 𝑥 ′ 𝑦 ′ 𝜎 𝑥 ′ 𝜎 𝑦 ′ = 𝜌 𝑥 𝑦 − 𝜌 𝑥 𝑧 𝜌 𝑦 𝑧 1 − 𝜌 𝑥 𝑧 2 1 − 𝜌 𝑦 𝑧 2

と表される。

4. 線形単回帰における回帰係数の区間推定

いま、誤差項𝜀𝑖は互いに独立で正規分布𝑁(0,𝜎2)に従う確率変数であるものとし、目的変数𝑦𝑖は説明変数𝑥𝑖と誤差項𝜀𝑖によって

𝑦 𝑖 = 𝛼 𝑥 𝑖 + 𝛽 + 𝜀 𝑖

と表されるものとする。 このとき、最小二乗法によって得られた回帰係数の点推定値𝛼̂および𝛽̂を考える（以下では主に𝛼̂について議論を行う）。

4.1. 回帰係数𝛼̂の分布

以下、𝑇○●≔∑𝑖(○𝑖−○)(●𝑖−●)と書くものとする。

𝑥と𝑦の偏差の積の和は

𝑇 𝑥 𝑦 = ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) ( 𝑦 𝑖 − 𝑦 ) = ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) ( 𝛼 ( 𝑥 𝑖 − 𝑥 ) + 𝜀 𝑖 ) = 𝑇 𝑥 𝑥 𝛼 + ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) 𝜀 𝑖

であるから、とくに重みを𝑤𝑖≔(𝑥𝑖−𝑥)𝑇𝑥𝑥−1とおけば次のように書ける。

𝛼 ̂ = 𝜎 𝑥 𝑦 𝜎 𝑥 2 = 𝑇 𝑥 𝑦 𝑇 𝑥 𝑥 = 𝛼 + ∑ 𝑖 𝑤 𝑖 𝜀 𝑖
[9]

とくにその平均と分散について

𝔼 [ 𝛼 ̂ ] = 𝔼 [ 𝛼 + ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 ] = 𝛼 + ∑ 𝑖 𝑤 𝑖 𝔼 [ 𝜀 𝑖 ] = 𝛼 Var ( 𝛼 ̂ ) = Var ( 𝛼 + ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 ) = Var ( ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 ) = ∑ 𝑖 𝑤 𝑖 2 Var ( 𝜀 𝑖 ) = 𝜎 2 ∑ 𝑖 𝑤 𝑖 2 = 𝜎 2 𝑇 𝑥 𝑥 se ( 𝛼 ̂ ) = 𝜎 𝑇 𝑥 𝑥

がいえるため、𝛼̂は𝛼の不偏推定量であり、また正規分布の再生性から𝛼̂は正規分布𝑁(𝛼,𝜎2𝑇𝑥𝑥)に従う。

4.2. 回帰係数𝛽̂の分布

式 [9]より

𝛽 ̂ = 𝑦 − 𝛼 ̂ 𝑥 = 𝑦 − 𝛼 𝑥 − 𝑥 ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 = 𝛽 − 𝑥 ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 + 𝜀
[10]

であるから、その平均と分散について

𝔼 [ 𝛽 ̂ ] = 𝔼 [ 𝛽 − 𝑥 ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 + 𝜀 ] = 𝛽 − 𝑥 ∑ 𝑖 𝑤 𝑖 𝔼 [ 𝜀 𝑖 ] + 𝑛 − 1 ∑ 𝑖 𝔼 [ 𝜀 𝑖 ] = 𝛽 Var ( 𝛽 ̂ ) = Var ( 𝛽 − 𝑥 ∑ 𝑖 𝑤 𝑖 𝜀 𝑖 + 𝜀 ) = ( 𝑥 ) 2 ∑ 𝑖 𝑤 𝑖 2 Var ( 𝜀 𝑖 ) + 𝑛 − 2 ∑ 𝑖 Var ( 𝜀 𝑖 ) = 𝜎 2 𝑛 [ ( 𝑥 𝜎 𝑥 ) 2 + 1 ] se ( 𝛽 ̂ ) = 𝜎 𝑛 ( 𝑥 𝜎 𝑥 ) 2 + 1

がいえるため、𝛽̂は𝛽の不偏推定量であり、また正規分布の再生性から𝛽̂は正規分布𝑁(𝛽,𝜎2𝑛[(𝑥𝜎𝑥)2+1])に従う。

4.3. 残差分散𝜎2̂の不偏推定量

いま、残差を𝛿𝑖≔𝑦𝑖−𝑦𝑖̂=(𝛼−𝛼̂)𝑥𝑖+(𝛽−𝛽̂)+𝜀𝑖とする。

式 [9]、式 [10]、および𝑤𝑖=(𝑥𝑖−𝑥)𝑇𝑥𝑥−1より
