1. 単回帰

相関とは、2変量(𝑥,𝑦)の間の間にある関係のことを指す。 相関に対して、説明変数𝑥から目的変数𝑦の予測を目指すことを単回帰という。

例えば一次関数による単回帰を考える。目的変数𝑦が説明変数𝑥の一次関数であると主張したいものとする。

𝑦 𝑖 ̂ = 𝛼 𝑥 𝑖 + 𝛽

しかしこのとき、実際には誤差𝜀が発生し、これを残差と呼ぶ。

𝑦 𝑖 = 𝛼 𝑥 𝑖 + 𝛽 + 𝜀 𝑖 ( = 𝑦 𝑖 ̂ + 𝜀 𝑖 )

よりよい説明のためには、残差が最小であることが望ましい。その基準として残差の分散𝜎𝜀2を最小化することが考えられる。

𝜎 𝜀 2 = 1 𝑛 ∑ 𝑖 𝜀 𝑖 2 = 1 𝑛 ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 𝑖 ̂ ) 2 = 1 𝑛 ∑ 𝑖 ( 𝛼 𝑥 𝑖 + 𝛽 − 𝑦 𝑖 ) 2

これを最小二乗法またはLSM(Least Squares Method)という。 （注：厳密には、残差の分散ではなく残差平方和∑𝑖𝜀𝑖2を最小化するものであるが、標本数𝑛を固定した場合これらは同一視できる。）

1.1. 最小二乗法による最適化

残差の分散を𝛼および𝛽について整理すると

𝜎 𝜀 2 = 1 𝑛 ∑ 𝑖 ( 𝑥 𝑖 𝛼 + 𝛽 − 𝑦 𝑖 ) 2 = 1 𝑛 ∑ 𝑖 ( 𝑥 𝑖 2 𝛼 2 + 2 𝑥 𝑖 𝛼 𝛽 + 𝛽 2 − 2 𝑥 𝑖 𝑦 𝑖 𝛼 − 2 𝑦 𝑖 𝛽 + 𝑦 𝑖 2 ) = ( 1 𝑛 ∑ 𝑖 𝑥 𝑖 2 ) 𝛼 2 + 2 ( 1 𝑛 ∑ 𝑖 𝑥 𝑖 ) 𝛼 𝛽 + 𝛽 2 − 2 ( 1 𝑛 ∑ 𝑖 𝑥 𝑖 𝑦 𝑖 ) 𝛼 − 2 ( 1 𝑛 ∑ 𝑖 𝑦 𝑖 ) 𝛽 + ( 1 𝑛 ∑ 𝑖 𝑦 𝑖 2 ) = ( 𝜎 𝑥 2 + ( 𝑥 ) 2 ) 𝛼 2 + 2 𝑥 𝛼 𝛽 + 𝛽 2 − 2 ( 𝜎 𝑥 𝑦 + 𝑥 𝑦 ) 𝛼 − 2 𝑦 𝛽 + 𝜎 𝑦 2 + ( 𝑦 ) 2

となる。

ここで𝛼と𝛽を変数とみれば、𝜎𝜀2は二次式であり、しかも𝛼2および𝛽2の係数は正であるため、𝜎𝜀2は凸関数である。

すなわち𝜎𝜀2は

𝜕 𝜕 𝛼 𝜎 𝜀 2 = 𝜕 𝜕 𝛽 𝜎 𝜀 2 = 0
[1]

たる点で最小値をとる。これをしばしば正規方程式という。

𝛼による偏微分

𝛼による偏微分を行うと

𝜕 𝜕 𝛼 𝜎 𝜀 2 = 2 ( 𝜎 𝑥 2 + ( 𝑥 ) 2 ) 𝛼 + 2 𝑥 𝛽 − 2 ( 𝜎 𝑥 𝑦 + 𝑥 𝑦 )

となり、式 [1]によれば最良の回帰𝑦𝑖̂=𝛼̂𝑥𝑖+𝛽̂は

( 𝜎 𝑥 2 + ( 𝑥 ) 2 ) 𝛼 ̂ + 𝑥 𝛽 ̂ = 𝜎 𝑥 𝑦 + 𝑥 𝑦
[2]

を満たす。

𝛽による偏微分

𝛽による偏微分を行うと

𝜕 𝜕 𝛽 𝜎 𝜀 2 = 2 𝑥 𝛼 + 2 𝛽 − 2 𝑦

となり、式 [1]によれば最良の回帰𝑦𝑖̂=𝛼̂𝑥𝑖+𝛽̂は

𝑥 𝛼 ̂ + 𝛽 ̂ = 𝑦
[3]

を満たす。

いま、式 [2]−𝑥×式 [3] を行うことで

𝑥 𝜎 𝑥 2 𝛼 ̂ = 𝑥 𝜎 𝑥 𝑦 ⟺ 𝛼 ̂ = 𝜎 𝑥 𝑦 𝜎 𝑥 2

であり、また式 [3]に代入することで

𝛽 ̂ = 𝑦 − 𝑥 𝛼 ̂ = 𝑦 − 𝜎 𝑥 𝑦 𝜎 𝑥 2 𝑥

がいえる。

ゆえに最良の回帰直線は

𝑦 𝑖 ̂ = 𝜎 𝑥 𝑦 𝜎 𝑥 2 ( 𝑥 𝑖 − 𝑥 ) + 𝑦
[4]

となる。あるいは相関係数𝜌𝑥𝑦を用いて

𝑦 𝑖 ̂ − 𝑦 𝜎 𝑦 = 𝜌 𝑥 𝑦 𝑥 𝑖 − 𝑥 𝜎 𝑥
[5]

ともかける。

1.2. 回帰直線の性質

  1. 式 [3]より、予測値𝑦𝑖̂の平均は観測値𝑦𝑖の平均と等しい
  2. すなわち、残差𝜀𝑖の平均は0となる
  3. 式 [5]より、回帰直線は点(𝑥,𝑦)を通る
  4. 予測値 𝑦 𝑖 ̂ と残差 𝜀 𝑖 の相関係数は 0 である
    ∵ 𝜌 𝑦 ̂ 𝜀 = 1 𝑛 ∑ 𝑖 ( 𝑦 𝑖 ̂ − 𝑦 ) ( 𝜀 𝑖 − 0 ) = 𝛼 ̂ 𝑛 ( 𝑥 𝑖 − 𝑥 ) ( 𝑦 𝑖 − 𝑦 − 𝛼 ̂ ( 𝑥 𝑖 − 𝑥 ) ) = 𝛼 ̂ 𝑛 ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) ( 𝑦 𝑖 − 𝑦 ) − 𝛼 ̂ 2 𝑛 ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) 2 = 𝛼 ̂ 𝜎 𝑥 𝑦 − 𝛼 ̂ 2 𝜎 𝑥 2 = 𝛼 ̂ 𝜎 𝑥 𝑦 − 𝛼 ̂ 𝜎 𝑥 𝑦 = 0
    [6]
  5. （平方和の分解）応答変数の偏差平方和は、回帰による平方和と残差平方和に分解できる
    ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 = ∑ 𝑖 [ ( 𝑦 𝑖 ̂ − 𝑦 ) + ( 𝑦 𝑖 − 𝑦 𝑖 ̂ ) ] 2 = ∑ 𝑖 [ ( 𝑦 𝑖 ̂ − 𝑦 ) + 𝜀 𝑖 ] 2 = ∑ 𝑖 ( 𝑦 𝑖 ̂ − 𝑦 ) 2 ⎵ 回帰による平方和 + ∑ 𝑖 𝜀 𝑖 2 ⎵ 残差平方和 ( ∵ 式 [6] )
    [7]

2. 決定係数

応答変数の偏差平方和を、回帰による平方和と残差平方和に分解したとき、その比率を決定係数あるいは寄与率という。式 [5]より決定係数は

∑ 𝑖 ( 𝑦 𝑖 ̂ − 𝑦 ) 2 ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 = 𝜌 𝑥 𝑦 2 𝜎 𝑦 2 ∑ 𝑖 ( 𝑥 𝑖 − 𝑥 ) 2 𝜎 𝑥 2 ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 = 𝜌 𝑥 𝑦 2 𝜎 𝑦 2 𝜎 𝑥 2 𝜎 𝑥 2 𝜎 𝑦 2 = 𝜌 𝑥 𝑦 2
[8]

とかけて、すなわち決定係数は相関係数の2乗である。

とくに式 [8]より式 [7]を変形すると

∑ 𝑖 𝜀 𝑖 2 = ( 1 − 𝜌 𝑥 𝑦 2 ) ∑ 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2

とかけて、とくに𝜌𝑥𝑦2=1のときは∑𝑖𝜀𝑖2=0となって、すべての観測値は回帰直線によって完全に決定されることが読み取れる。

3. 偏相関係数

いま、3つの変量𝑥、𝑦、𝑧があり、𝑥と𝑦の相関係数を求めたいとする。しかし𝑥と𝑦の間には変量𝑧の影響があり、それが本当に𝑥と𝑦の相関を反映しているとは限らない。そこでその影響が𝑧による回帰式

𝑥 𝑖 ̂ = 𝑎 𝑧 𝑖 + 𝑏 , 𝑦 𝑖 ̂ = 𝑐 𝑧 𝑖 + 𝑑

で説明できるものと仮定し、その影響を除いた変量

𝑥 𝑖 ′ ≔ 𝑥 𝑖 − 𝑥 𝑖 ̂ , 𝑦 𝑖 ′ ≔ 𝑦 𝑖 − 𝑦 𝑖 ̂

による相関係数𝜌𝑥′𝑦′を考える。これを偏相関係数といって𝜌𝑥𝑦∙𝑧と表すものとする。

式 [4]と同様にして

𝑥 𝑖 ′ = 𝑥 𝑖 − 𝑥 − 𝜎 𝑥 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) , 𝑦 𝑖 ′ = 𝑦 𝑖 − 𝑦 − 𝜎 𝑦 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 )

により、𝑥′=𝑦′=0に注意して

𝜎 𝑥 ′ 2 = 1 𝑛 ∑ 𝑖 𝑥 𝑖 ′ 2 = 1 𝑛 ∑ 𝑖 [ ( 𝑥 𝑖 − 𝑥 ) − 𝜎 𝑥 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] 2 = 𝜎 𝑥 2 − 𝜎 𝑥 𝑧 2 𝜎 𝑧 2 = 𝜎 𝑥 2 ( 1 − 𝜌 𝑥 𝑧 2 ) 𝜎 𝑦 ′ 2 = 1 𝑛 ∑ 𝑖 𝑦 𝑖 ′ 2 = 1 𝑛 ∑ 𝑖 [ ( 𝑦 𝑖 − 𝑦 ) − 𝜎 𝑦 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] 2 = 𝜎 𝑦 2 − 𝜎 𝑦 𝑧 2 𝜎 𝑧 2 = 𝜎 𝑦 2 ( 1 − 𝜌 𝑦 𝑧 2 ) 𝜎 𝑥 ′ 𝑦 ′ = 1 𝑛 ∑ 𝑖 𝑥 𝑖 ′ 𝑦 𝑖 ′ = 1 𝑛 ∑ 𝑖 [ ( 𝑥 𝑖 − 𝑥 ) − 𝜎 𝑥 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] [ ( 𝑦 𝑖 − 𝑦 ) − 𝜎 𝑦 𝑧 𝜎 𝑧 2 ( 𝑧 𝑖 − 𝑧 ) ] = 𝜎 𝑥 𝑦 − 𝜎 𝑥 𝑧 𝜎 𝑦 𝑧 𝜎 𝑧 2 = 𝜎 𝑥 𝜎 𝑦 ( 𝜌 𝑥 𝑦 − 𝜌 𝑥 𝑧 𝜌 𝑦 𝑧 )

であるから、偏相関係数は

𝜌 𝑥 𝑦 ∙ 𝑧 = 𝜎 𝑥 ′ 𝑦 ′ 𝜎 𝑥 ′ 𝜎 𝑦 ′ = 𝜌 𝑥 𝑦 − 𝜌 𝑥 𝑧 𝜌 𝑦 𝑧 1 − 𝜌 𝑥 𝑧 2 1 − 𝜌 𝑦 𝑧 2

と表される。
