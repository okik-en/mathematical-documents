1. Γ分布

1.1. Γ関数

Γ関数は𝛼>0で以下のように定義される関数である。

Γ ( 𝛼 ) = ∫ 0 ∞ 𝑡 𝛼 − 1 𝑒 − 𝑡 𝑑 𝑡

Γ関数は以下の性質を満たす。

  1. Γ(1)=1、Γ(12)=𝜋
  2. Γ(𝛼+1)=𝛼Γ(𝛼)

これらより、𝑛∈ℕについてΓ(𝑛+1)=𝑛!が言える。

次のように覚えておいてもよいだろう。

∫ 0 ∞ 𝑡 𝑛 𝑒 − 𝑡 𝑑 𝑡 = 𝑛 !

1.2. 指数分布とΓ分布

𝜆>0について、指数分布の確率密度関数は次式で与えられた。

𝑓 ( 𝑥 ; 𝜆 ) = 𝜆 𝑒 − 𝜆 𝑥 ( 𝑥 > 0 )

これをパラメータ𝛼>0により拡張した次の確率密度関数で与えられる分布をΓ分布といい、Γ(𝛼,𝜆)で表す。

𝑓 ( 𝑥 ; 𝛼 , 𝜆 ) = 𝜆 𝛼 Γ ( 𝛼 ) 𝑥 𝛼 − 1 𝑒 − 𝜆 𝑥 ( 𝑥 > 0 )

ただし、𝛼→1とすれば指数分布に一致することに留意せよ。

1.3. Γ分布の再生性

Γ分布に従う確率変数𝑋∼Γ(𝛼,𝜆)を考える。

いま、Γ関数の定義式において𝑡=𝜈𝑥(⟹𝑑𝑡=𝜈𝑑𝑥)とおくことで

Γ ( 𝛼 ) = ∫ 0 ∞ ( 𝜈 𝑥 ) 𝛼 − 1 𝑒 − 𝜈 𝑥 𝜈 𝑑 𝑥 = 𝜈 𝛼 ∫ 0 ∞ 𝑥 𝛼 − 1 𝑒 − 𝜈 𝑥 𝑑 𝑥

が得られ、これにより𝑡<𝜆についてそのモーメント母関数は

𝑀 𝑋 ( 𝑡 ; 𝛼 , 𝜆 ) = ∫ 0 ∞ 𝑒 𝑡 𝑥 𝜆 𝛼 Γ ( 𝛼 ) 𝑥 𝛼 − 1 𝑒 − 𝜆 𝑥 𝑑 𝑥 = 𝜆 𝛼 Γ ( 𝛼 ) ∫ 0 ∞ 𝑥 𝛼 − 1 𝑒 − ( 𝜆 − 𝑡 ) 𝑥 𝑑 𝑥 = 𝜆 𝛼 Γ ( 𝛼 ) Γ ( 𝛼 ) ( 𝜆 − 𝑡 ) 𝛼 = ( 𝜆 𝜆 − 𝑡 ) 𝛼

と書ける。

この式から、𝑋1および𝑋2が独立であれば

𝑋 1 ∼ Γ ( 𝛼 1 , 𝜆 ) ∧ 𝑋 2 ∼ Γ ( 𝛼 2 , 𝜆 ) ⟹ 𝑋 1 + 𝑋 2 ∼ Γ ( 𝛼 1 + 𝛼 2 , 𝜆 )

が成り立つことがわかる。 この性質をΓ分布の再生性という。

2. 𝜒2分布

2.1. 𝜒2分布の定義

独立な標本𝑍1,…,𝑍𝑛がそれぞれ標準正規分布𝑁(0,1)に従うととする。 このとき、新たな確率変数𝑋=∑𝑖=1𝑛𝑍𝑖2の従う分布を自由度𝑛の𝜒2分布（chi-squared distribution）といい、𝜒2(𝑛)で表す。

また、自由度𝑛の𝜒2分布について、その上側𝛼点を𝜒𝑛(𝛼)で表すものとする。

2.2. 𝜒2分布の再生性

𝜒2(𝑛)はΓ(𝑛2,12)と一致することが知られている。 数学的帰納法による略証を以下に示す。

  1. 𝑍∼𝑁(0,1)とすれば、𝑋=𝑍2は𝜒2(1)に従い、また𝑥≥0について

    𝑋 ≤ 𝑥 ⟺ 𝑍 2 ≤ 𝑥 ⟺ | 𝑍 | ≤ 𝑥 ⟺ − 𝑥 ≤ 𝑍 ≤ 𝑥

    であるから、その分布関数𝐹(𝑥)について

    𝐹 ( 𝑥 ) = Pr { 𝑋 ≤ 𝑥 } = Pr { − 𝑥 ≤ 𝑍 ≤ 𝑥 } = 1 2 𝜋 ∫ − 𝑥 𝑥 𝑒 − 𝑧 2 2 𝑑 𝑧

    が得られ、ゆえに確率密度関数𝑓(𝑥)=𝐹′(𝑥)は

    𝑓 ( 𝑥 ) = 𝑑 𝑑 𝑥 𝐹 ( 𝑥 ) = 1 2 𝜋 𝑥 𝑒 − 𝑥 2

    と表せる。これはΓ(12,12)に一致する。

  2. 任意の𝑘∈ℕをとり、𝜒2(𝑘)がΓ(𝑘2,12)に一致するものとする。 𝑍1,…,𝑍𝑘+1∼𝑁(0,1)とすれば、𝑋=𝑍12+⋯+𝑍𝑘2+𝑍𝑘+12は𝜒2(𝑘+1)に従う。 ここで𝑋′=𝑍12+⋯+𝑍𝑘2はΓ(𝑘2,12)に従い、𝑍𝑘+12はΓ(12,12)に従うため、Γ分布の再生性により𝑋=𝑋′+𝑍𝑘+12はΓ(𝑘+12,12)に従う。

これにより、𝜒2分布はΓ分布と同じように再生性をもつことが示された。

3. 𝑡分布

3.1. 𝑡分布の定義

独立な確率変数𝑋∼𝜒2(𝑛)、𝑍∼𝑁(0,1)について、新たな確率変数𝑇=𝑍(𝑋/𝑛)が従う分布を自由度𝑛の𝑡分布（t-distribution）といい、𝑡(𝑛)で表す。

また、自由度𝑛の𝑡分布について、その上側𝛼点を𝑡𝑛(𝛼)で表すものとする。

4. 𝐹分布

4.1. 𝐹分布の定義

独立な確率変数𝑋∼𝜒2(𝑚)、𝑌∼𝜒2(𝑛)について、新たな確率変数𝐹=(𝑋/𝑚)(𝑌/𝑛)が従う分布を自由度(𝑚,𝑛)の𝐹分布（F-distribution）といい、𝐹(𝑚,𝑛)で表す。

また、自由度(𝑚,𝑛)の𝐹分布について、その上側𝛼点を𝐹𝑛𝑚(𝛼)で表すものとする。

4.2. 𝐹分布の交換性

0<𝛼<1について、𝐹∼𝐹(𝑛,𝑚)とすれば

𝛼 = Pr { 𝐹 ≥ 𝐹 𝑚 𝑛 ( 𝛼 ) } = Pr { 1 𝐹 ≤ 1 𝐹 𝑚 𝑛 ( 𝛼 ) } = 1 − Pr { 1 𝐹 ≥ 1 𝐹 𝑚 𝑛 ( 𝛼 ) }

であり、ゆえに

Pr { 1 𝐹 ≥ 1 𝐹 𝑚 𝑛 ( 𝛼 ) } = 1 − 𝛼

である。ここで定義から1𝐹∼𝐹(𝑚,𝑛)であり

𝐹 𝑛 𝑚 ( 1 − 𝛼 ) = 1 𝐹 𝑚 𝑛 ( 𝛼 )

が示された。

5. 統計量

5.1. 不偏分散に関する統計量

𝑋1,…,𝑋𝑛を𝑁(𝜇,𝜎2)からの無作為標本とする。

標本平均𝑋=1𝑛∑𝑖=1𝑛𝑋𝑖と不偏分散𝑈2=1𝑛−1∑𝑖=1𝑛(𝑋𝑖−𝑋)2が既知であるとする。

いま、標本平均𝑋について

∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝑋 ) = ∑ 𝑖 = 1 𝑛 𝑋 𝑛 − 𝑛 𝑋 = 0

である（すなわち、𝑋𝑖−𝑋の自由度は高々𝑛−1である）ことに注意して次を議論する。

5.1.1. 𝜒2変量

標本𝑋1,…,𝑋𝑛について、これらを標準化した変量

𝑍 𝑖 = 𝑋 𝑖 − 𝜇 𝜎 ( 𝑖 = 1 , … , 𝑛 )

を考えると、それぞれ𝑍𝑖∼𝑁(0,1)であるから、統計量𝑊を

𝑊 = ∑ 𝑖 = 1 𝑛 𝑍 𝑖 2

で定義すれば、𝑊は自由度𝑛の𝜒2分布に従う。

5.1.2. 𝑍統計量

標本平均𝑋について、これを標準化した統計量

𝑍 = 𝑋 − 𝜇 ( 𝜎 / 𝑛 )

を考えると、𝑍∼𝑁(0,1)であるから、𝑍2は自由度1の𝜒2分布に従う。

5.1.3. 𝜒2統計量

標本𝑋1,…,𝑋𝑛について、これらを「標本平均𝑋により」標準化した変量

𝑍 𝑖 ′ = 𝑋 𝑖 − 𝑋 𝜎 ( 𝑖 = 1 , … , 𝑛 )

を考える。 これについて新たな統計量

𝑌 = ∑ 𝑖 = 1 𝑛 𝑍 𝑖 ′ 2 = ( 𝑛 − 1 ) 𝑈 2 𝜎 2

を考えると、

𝑌 = ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝑋 𝜎 ) 2 = ∑ 𝑖 = 1 𝑛 [ ( 𝑋 𝑖 − 𝜇 ) − ( 𝑋 − 𝜇 ) 𝜎 ] 2 = ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝜇 𝜎 ) 2 − 2 𝑋 − 𝜇 𝜎 2 ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝜇 ) ⎵ = 0 + 𝑛 ( 𝑋 − 𝜇 𝜎 ) 2 = ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝜇 𝜎 ) 2 − ( 𝑋 − 𝜇 ( 𝜎 / 𝑛 ) ) 2 = 𝑊 − 𝑍 2

を得る。 𝑊と𝑍2は独立だから、𝜒2分布の再生性より、𝑌=𝑊−𝑍2は自由度𝑛−1の𝜒2分布に従う。

5.1.4. スチューデントの𝑡統計量

𝑍統計量は母分散𝜎2を既知とする統計量であるが、必ずしも既知とは限らないため、代わりに不偏分散𝑈2を用いた別の統計量

𝑇 = 𝑋 − 𝜇 ( 𝑈 / 𝑛 )

を考えると、

𝑇 = ( 𝑋 − 𝜇 ( 𝜎 / 𝑛 ) / ( 𝑛 − 1 ) 𝑈 2 𝜎 2 𝑛 ) = 𝑍 ( 𝑌 / 𝑛 )

より𝑍∼𝑁(0,1)と𝑌∼𝜒2(𝑛−1)は独立であり、定義より𝑇は自由度𝑛−1の𝑡分布に従う。

この統計量𝑇はスチューデントの𝑡統計量（Student’s t-statistic）と呼ばれる。

5.2. ピアソンの𝜒2統計量

事象𝐴1,…,𝐴𝑘は互いに排反で、各事象が起こる確率を𝑝𝑖とし、𝑛個の標本を抽出したとき𝐴𝑖が出現した回数を𝑋𝑖とする。

𝑛が十分大きいとき、ピアソンの定理（Pearson’s theorem）によれば、統計量

𝑇 = ∑ 𝑖 = 1 𝑘 ( 𝑋 𝑖 − 𝑛 𝑝 𝑖 ) 2 𝑛 𝑝 𝑖

は自由度𝑘−1の𝜒2分布に従うことが知られる。

この統計量𝑇はピアソンの𝜒2統計量（Pearson’s chi-squared statistic）と呼ばれる。

5.3. 2標本問題

𝑁(𝜇1,𝜎12)に従う無作為標本𝑋1,…,𝑋𝑚と𝑁(𝜇2,𝜎22)に従う無作為標本𝑌1,…,𝑌𝑛があり、それぞれは独立とする。 それぞれの標本平均を𝑋と𝑌、不偏分散を𝑈12と𝑈22とする。

5.3.1. 母分散が既知のとき

それぞれの標本平均は、𝑋は𝑁(𝜇1,𝜎12𝑚)に、𝑌は𝑁(𝜇2,𝜎22𝑛)に従うため、差𝐷=𝑋−𝑌は正規分布の再生性より𝑁(𝜇1−𝜇2,𝜎12𝑚+𝜎22𝑛)に従う。 すなわち統計量

𝑍 = 𝐷 − ( 𝜇 1 − 𝜇 2 ) ( 𝜎 1 2 / 𝑚 ) + ( 𝜎 2 2 / 𝑛 )

は標準正規分布𝑁(0,1)に従う。

5.3.2. 母分散が未知で等しいとき

それぞれの𝜒2統計量(𝑚−1)𝑈12𝜎2と(𝑛−1)𝑈22𝜎2はそれぞれ独立に𝜒2(𝑚−1)および𝜒2(𝑛−1)に従うため、𝜒2分布の再生性より

𝑌 = ( 𝑚 − 1 ) 𝑈 1 2 𝜎 2 + ( 𝑛 − 1 ) 𝑈 2 2 𝜎 2 = 𝑚 + 𝑛 − 2 𝜎 2 ⋅ ( 𝑚 − 1 ) 𝑈 1 2 + ( 𝑛 − 1 ) 𝑈 2 2 𝑚 + 𝑛 − 2 ⎵ ≜ 𝑈 2 = ( 𝑚 + 𝑛 − 2 ) 𝑈 2 𝜎 2

は𝜒2(𝑚+𝑛−2)に従う。 また𝑍=𝐷−(𝜇1−𝜇2)𝜎(1/𝑚)+(1/𝑛)は𝑁(0,1)に従うため、𝑌と𝑍が独立であることから、統計量

𝑇 = ( 𝑍 / 𝑌 𝑚 + 𝑛 − 2 ) = 𝑍 ⋅ 𝜎 𝑈 = 𝐷 − ( 𝜇 1 − 𝜇 2 ) 𝑈 ( 1 / 𝑚 ) + ( 1 / 𝑛 )

5.3.3. 母分散が未知で等しくないとき

𝜎12の代わりに𝑈12、𝜎22の代わりに𝑈22を用いるというウェルチの近似法（Welch’s approximation）により、統計量

𝑇 0 = 𝐷 − ( 𝜇 1 − 𝜇 2 ) ( 𝑈 1 2 / 𝑚 ) + ( 𝑈 2 2 / 𝑛 )

は、近似的に自由度が

𝑐 = ( ( 𝑈 1 2 / 𝑚 ) + ( 𝑈 2 2 / 𝑛 ) ) 2 ( ( 𝑈 1 2 / 𝑚 ) ) 2 𝑚 − 1 + ( ( 𝑈 2 2 / 𝑛 ) ) 2 𝑛 − 1

に最も近い自然数𝑘の𝑡分布𝑡(𝑘)に従うことが知られている。

5.3.4. 母平均が未知で母分散が既知のとき

それぞれの𝜒2統計量(𝑚−1)𝑈12𝜎12と(𝑛−1)𝑈22𝜎22はそれぞれ独立に𝜒2(𝑚−1)および𝜒2(𝑛−1)に従うため、𝐹分布の定義より

6. 検定

6.1. 𝜒2検定

6.1.1. 分散の検定

平均𝜇、分散𝜎2がともに未知である正規分布𝑁(𝜇,𝜎2)の母分散𝜎2の検定を考える。

いま、「𝜎2=𝜎02」を仮定すると、不偏分散𝑈2について𝜒2統計量

𝑌 = ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝑋 𝜎 ) 2 = ( 𝑛 − 1 ) 𝑈 2 𝜎 0 2

は自由度𝑛−1の𝜒2分布𝜒2(𝑛−1)に従い、とくに有意水準を𝛼とすれば

両側検定
𝑌∈{𝑦|𝑦<𝜒𝑛−12(1−𝛼2),𝑦>𝜒𝑛−12(𝛼2)}⟹𝜎2≠𝜎02
右側検定
𝑌∈{𝑦|𝑦>𝜒𝑛−12(𝛼)}⟹𝜎2>𝜎02
左側検定
𝑌∈{𝑦|𝑦<𝜒𝑛−12(1−𝛼)}⟹𝜎2<𝜎02

がいえる。

6.1.2. 適合度の検定

母集団が互いに排反な𝑘個の事象𝐴1,…,𝐴𝑘に分割されているとき、各事象における母比率𝑃(𝐴1),…,𝑃(𝐴𝑘)の検定を考える。

いま、「∀𝑖∈{1,…,𝑘}:𝑃(𝐴𝑖)=𝑝𝑖」を仮定すると、十分大きい𝑛でピアソンの𝜒2統計量

𝑇 = ∑ 𝑖 = 1 𝑘 ( 𝑋 𝑖 − 𝑛 𝑝 𝑖 ) 2 𝑛 𝑝 𝑖

は自由度𝑘−1の𝜒2分布に従い、とくに有意水準を𝛼とすれば

𝑇 ∈ { 𝑡 | 𝑡 > 𝜒 𝑘 − 1 2 ( 𝛼 ) } ⟹ ∃ 𝑖 ∈ { 1 , … , 𝑘 } : 𝑃 ( 𝐴 𝑖 ) ≠ 𝑝 𝑖
