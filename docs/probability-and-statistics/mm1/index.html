1. ポアソン過程

次を満たすモデルをポアソン過程と定める。

独立性
出来事が起きるのはたがいに独立である。
定常性
出来事が起きる確率はどの時間帯でも同じである。
希少性
微小時間Δ𝑡の間にその出来事が2回以上起きる確率は𝜊(Δ𝑡)である。

ただし希少性について、微小時間Δ𝑡の間にその出来事が起きる確率は𝜆Δ𝑡であるものとする。 この𝜆を生起率（単位時間当たりの出来事数を指す）という。

ポアソン過程について、以下の二面から分布を考えることができる。

ポアソン分布
出来事が起こる回数
指数分布
出来事が起こる時間間隔

2. ポアソン分布

時間間隔(0,𝑡]の中で、出来事が𝑘回起きる確率を𝑃𝑘(𝑡)とする。 このとき𝑃𝑘(𝑡)のなす確率分布はポアソン分布𝑃𝑜(𝜆𝑡)であることが知られている。 すなわち：

𝑃 𝑘 ( 𝑡 ) = ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡

2.1. 微分方程式による導出

ポアソン過程の希少性より、時刻𝑡+Δ𝑡において出来事が𝑛回起こっている場合は次のいずれかによるとみなせる。

  1. 時刻𝑡において出来事がすでに𝑛回起こっていて、かつ時刻𝑡から𝑡+Δ𝑡の間に出来事が起こらない場合。
  2. 時刻𝑡において出来事が𝑛−1回起こっていて、かつ時刻𝑡から𝑡+Δ𝑡の間に出来事が1回起こる場合。ただし𝑛=0のときを除く。

これより次の方程式が得られる。

𝑃 𝑛 ( 𝑡 + Δ 𝑡 ) ≈ 𝑃 𝑛 ( 𝑡 ) ( 1 − 𝜆 Δ 𝑡 ) ⎴ 1. + 𝑃 𝑛 − 1 ( 𝑡 ) ( 𝜆 Δ 𝑡 ) ⎴ 2.

すなわちΔ𝑡→0として

𝑑 𝑃 𝑛 ( 𝑡 ) 𝑑 𝑡 + 𝜆 𝑃 𝑛 ( 𝑡 ) = 𝜆 𝑃 𝑛 − 1 ( 𝑡 )

を得て、この斉次一般解は

𝑃 𝑛 ( 𝑡 ) = 𝐴 𝑒 − 𝜆 𝑡

である。

いま𝑛=0を仮定すると斉次部分のみが残り、希少性より

𝑃 0 ( 𝑡 ) = 𝑒 − 𝜆 𝑡

を得る。

これを基底ケースとして帰納法を用いることにより

𝑃 𝑛 ( 𝑡 ) = ( 𝜆 𝑡 ) 𝑛 𝑛 ! 𝑒 − 𝜆 𝑡

を得る。

2.2. コーシーの関数方程式による導出

ポアソン過程の独立性と定常性からコーシーの関数方程式

𝑃 0 ( 𝑡 1 + 𝑡 2 ) = 𝑃 0 ( 𝑡 1 ) 𝑃 0 ( 𝑡 2 )

に帰着され、これは𝑃0の連続性を仮定すれば

𝑃 0 ( 𝑡 ) = 0 , 𝑃 0 ( 𝑡 ) = 𝐴 𝑒 − 𝐵 𝑡

と解ける。しかし前者は不適であるため、後者を採択する。

希少性より𝐴=1、𝐵=𝜆であり、すなわち次を得る：

𝑃 0 ( 𝑡 ) = 𝑒 − 𝜆 𝑡

3. 指数分布

時間間隔𝑇(>0)の間に出来事が1回も起きない確率𝑆(𝑇)は

𝑆 ( 𝑇 ) = 𝑃 0 ( 𝑇 ) = 𝑒 − 𝜆 𝑇

である（ただし、𝑆(𝑇)=0(𝑇<0)を約束する）。

つまり関数その確率密度関数𝑓(𝑡)について

∫ 𝑇 ∞ 𝑓 ( 𝑡 ) 𝑑 𝑡 = 𝑆 ( 𝑇 ) = 𝑒 − 𝜆 𝑇

が成り立つため、この両辺を𝑇で微分することで

𝑓 ( 𝑇 ) = 𝜆 𝑒 − 𝜆 𝑇

を得る。

補足。 𝑆はコーシーの関数方程式

𝑆 ( 𝑇 1 + 𝑇 2 ) = 𝑆 ( 𝑇 1 ) 𝑆 ( 𝑇 2 )

を満たすことが知られる。 逆にこれを満たす非零連続関数は指数分布ただ一つである。

4. 待ち行列モデル

𝑀/𝑀/1モデルとは次の条件を満たす待ち行列モデルである。

客の到着過程
生起率𝜆のポアソン分布
客の処理時間
生起率𝜇の指数分布

時刻𝑡において、系内に客が𝑛人いる確率を𝑃𝑛(𝑡)とする。

ポアソン過程の希少性より、時刻𝑡+Δ𝑡において系内に客が𝑛人いる場合は次のいずれかによるとみなせる。

  1. 時刻𝑡において客がすでに𝑛人いて、かつ時刻𝑡から𝑡+Δ𝑡の間に客が到着せず、かつ客が処理されない場合。
  2. 時刻𝑡において客が𝑛−1人いて、かつ時刻𝑡から𝑡+Δ𝑡の間に客が1人到着する場合。ただし𝑛=0のときを除く。
  3. 時刻𝑡において客が𝑛+1人いて、かつ時刻𝑡から𝑡+Δ𝑡の間に客が1人処理される場合。

これより次の方程式が得られる。

𝑃 𝑛 ( 𝑡 + Δ 𝑡 ) ≈ 𝑃 𝑛 ( 𝑡 ) ( 1 − 𝜆 Δ 𝑡 − 𝜇 Δ 𝑡 ) ⎴ 1. + 𝑃 𝑛 − 1 ( 𝑡 ) ( 𝜆 Δ 𝑡 ) ⎴ 2. + 𝑃 𝑛 + 1 ( 𝑡 ) ( 𝜇 Δ 𝑡 ) ⎴ 3.

すなわちΔ𝑡→0として

𝑑 𝑃 𝑛 ( 𝑡 ) 𝑑 𝑡 + ( 𝜆 + 𝜇 ) 𝑃 𝑛 ( 𝑡 ) = 𝜆 𝑃 𝑛 − 1 ( 𝑡 ) + 𝜇 𝑃 𝑛 + 1 ( 𝑡 )

を得る。同時に𝑡→∞において定常状態lim𝑡→∞𝑃𝑛(𝑡)=𝑃𝑛となることを仮定して

𝜇 𝑃 𝑛 + 1 − ( 𝜆 + 𝜇 ) 𝑃 𝑛 + 𝜆 𝑃 𝑛 − 1 = 0

とできて、さらに利用率𝜌=𝜆𝜇を用いることで

𝑃 𝑛 + 1 − ( 1 + 𝜌 ) 𝑃 𝑛 + 𝜌 𝑃 𝑛 − 1 = 0

とかける。

これを解くことにより

𝑃 𝑛 = ( 1 − 𝜌 ) 𝜌 𝑛

が得られる。 これは幾何分布と呼ばれる。

ここで定常状態における系内の平均客数は

𝐿 = 𝔼 [ 𝑛 ] = ∑ 𝑛 = 0 ∞ 𝑃 𝑛 𝑛 = ( 1 − 𝜌 ) ∑ 𝑛 = 0 ∞ 𝑛 𝜌 𝑛 = 𝜌 1 − 𝜌

であり、平均占有時間（スループットタイム）は、自分自身の処理を含めて

𝑊 = 𝔼 [ 𝑛 + 1 𝜇 ] = ∑ 𝑛 = 0 ∞ 𝑃 𝑛 𝑛 + 1 𝜇 = 𝐿 + 1 𝜇 = 1 𝜇 ⋅ 1 1 − 𝜌

と求まる。

ここでこれらにおいて満たされる関係式

𝐿 = 𝜆 𝑊

をリトルの公式という。
