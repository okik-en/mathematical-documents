回帰係数の推定

最小二乗法で求めた回帰係数は、データから計算した推定値であり、標本が変われば値も変わる。 このページでは、その推定値がどのくらいぶれるか（分布・標準誤差）と、信頼区間の作り方をまとめる。 導出の詳細は線形単回帰と最小二乗法を参照のこと。

注意：記号について

元のページでは回帰直線を𝑦=𝛼𝑥+𝛽と書いているが、このページでは有意水準の𝛼と区別するため

𝑦 = 𝛽 0 + 𝛽 1 𝑥

と書く。元のページの𝛼（傾き）が𝛽1、𝛽（切片）が𝛽0に対応する。

1. モデルと推定量

定義：単回帰モデル

𝑌 𝑖 = 𝛽 0 + 𝛽 1 𝑥 𝑖 + 𝜀 𝑖 , 𝜀 𝑖 ∼ 𝑁 ( 0 , 𝜎 2 ) （独立） ( 𝑖 = 1 , … , 𝑛 )

𝑥𝑖は確率変数ではなく、与えられた値とみなす。

𝑆𝑥𝑥=∑(𝑥𝑖−𝑥)2、𝑆𝑥𝑦=∑(𝑥𝑖−𝑥)(𝑦𝑖−𝑦)とおくと、最小二乗推定量は

𝛽 ̂ 1 = 𝑆 𝑥 𝑦 𝑆 𝑥 𝑥 , 𝛽 ̂ 0 = 𝑦 − 𝛽 ̂ 1 𝑥

である。

2. 推定量の分布

定理

  1. 𝛽̂1、𝛽̂0はそれぞれ𝛽1、𝛽0の不偏推定量である。

  2. 分散は

    Var [ 𝛽 ̂ 1 ] = 𝜎 2 𝑆 𝑥 𝑥 , Var [ 𝛽 ̂ 0 ] = 𝜎 2 ( 1 𝑛 + 𝑥 2 𝑆 𝑥 𝑥 )
  3. 𝛽̂1、𝛽̂0は正規分布に従う。

𝛽̂1が𝑌𝑖（したがって𝜀𝑖）の1次式で書けることから、正規分布の再生性によって正規分布に従う。

覚え方

  • 𝛽̂1の分散は𝜎2𝑆𝑥𝑥。 誤差が小さい（𝜎が小さい）ほど、𝑥が広く散らばっている（𝑆𝑥𝑥が大きい）ほど、傾きは安定する。 実験で𝑥を選べるなら、なるべく広い範囲にとるとよい。
  • 𝛽̂0の分散は、𝑥が0から遠いほど大きい。 切片は𝑥=0での値なので、データの中心から遠いところへ延長するほど不確かになる。

3. 誤差分散の推定と標準誤差

𝜎2は未知なので、残差𝑒𝑖=𝑦𝑖−𝑦̂𝑖から推定する。

定理

𝑠 2 = 1 𝑛 − 2 ∑ 𝑖 = 1 𝑛 𝑒 𝑖 2

は𝜎2の不偏推定量であり、(𝑛−2)𝑠2𝜎2∼𝜒2(𝑛−2)。 また𝑠2は𝛽̂0、𝛽̂1と独立である。

覚え方

𝑛 − 2 で割るのは、 𝛽 0 と 𝛽 1 の2つのパラメータを推定したから。 標本分散を 𝑛 − 1 で割るのと同じ理由（推定したパラメータの数だけ自由度が減る）。

定義：標準誤差

分散の式の𝜎を𝑠で置き換えたものを標準誤差という。

se ( 𝛽 ̂ 1 ) = 𝑠 𝑆 𝑥 𝑥 , se ( 𝛽 ̂ 0 ) = 𝑠 1 𝑛 + 𝑥 2 𝑆 𝑥 𝑥

定理

𝑇 = 𝛽 ̂ 1 − 𝛽 1 se ( 𝛽 ̂ 1 ) ∼ 𝑡 ( 𝑛 − 2 )

（𝛽̂0についても同様。）

これは、母平均の推定で𝑋−𝜇𝑈/𝑛∼𝑡(𝑛−1)となるのとまったく同じ構造である。

4. 信頼区間

定理

𝛽1の100(1−𝛼)%信頼区間は

𝛽 ̂ 1 − 𝑡 𝑛 − 2 ( 𝛼 2 ) se ( 𝛽 ̂ 1 ) ≤ 𝛽 1 ≤ 𝛽 ̂ 1 + 𝑡 𝑛 − 2 ( 𝛼 2 ) se ( 𝛽 ̂ 1 )

覚え方

「推定値 ± 𝑡の点 × 標準誤差」。どの信頼区間もこの形。

例題

𝑛 = 12 組のデータで単回帰したところ、 𝛽 ̂ 1 = 0.8 、 se ( 𝛽 ̂ 1 ) = 0.3 だった。 𝛽 1 の 95 % 信頼区間を求めよ。

自由度10で𝑡10(0.025)≈2.228なので

0.8 ± 2.228 × 0.3 = 0.8 ± 0.668

より、95%信頼区間は[0.132,1.468]。

この区間は0を含まないので、有意水準5%の両側検定で𝐻0:𝛽1=0は棄却される（回帰係数の検定を参照）。

5. 自由度が大きいときの正規近似

𝑡分布は自由度が大きくなると標準正規分布に近づく。 そのため、残差の自由度𝑛−2（重回帰なら𝑛−𝑝−1）が十分大きいときは、𝑡分布の点の代わりに正規分布の点を使ってよい。

定理

自由度𝜈→∞のとき𝑡(𝜈)→𝑁(0,1)。したがって𝜈が大きければ近似的に

𝛽 ̂ 1 − 𝛽 1 se ( 𝛽 ̂ 1 ) ∼ 𝑁 ( 0 , 1 )

であり、95%信頼区間は

𝛽 ̂ 1 ± 1.96 se ( 𝛽 ̂ 1 )

で近似できる。

𝑡分布の上側点が𝑧の値にどのくらい近づくかを見ると、次のとおり。

自由度 𝑡(0.025) 𝑡(0.05)
5 2.571 2.015
10 2.228 1.812
20 2.086 1.725
30 2.042 1.697
60 2.000 1.671
120 1.980 1.658
∞（正規分布） 1.960 1.645

例題

𝑛 = 102 組のデータで単回帰したところ、 𝛽 ̂ 1 = 0.5 、 se ( 𝛽 ̂ 1 ) = 0.2 だった。 正規近似を用いて 𝛽 1 の 95 % 信頼区間を求め、 𝐻 0 : 𝛽 1 = 0 を有意水準 5 % で両側検定せよ。

自由度は100と大きいので正規近似を用いる。

0.5 ± 1.96 × 0.2 = 0.5 ± 0.392

より、95%信頼区間は[0.108,0.892]。

検定統計量は𝑧=0.5/0.2=2.5>1.96なので、𝐻0を棄却する（𝑝≈0.012）。

参考：𝑡(100)を正確に使うと𝑡100(0.025)≈1.984で、信頼区間は[0.103,0.897]。ほとんど変わらない。

覚え方

  • 自由度が30を超えたら𝑡≈𝑧とみなしてよい、というのが目安（100以上ならほぼ確実）。
  • 正規近似を使うと、𝑡分布表を引かずに1.96（両側5%）、2.576（両側1%）で判断できる。
  • 「|𝑡|>2なら大体5%有意」という経験則も、自由度が大きいときの正規近似から来ている。
  • 自由度が小さいとき（例えば10）に1.96を使うと、区間が狭くなりすぎ、有意になりやすくなる（第1種の過誤が増える）ので注意。

注意

正規近似は誤差項 𝜀 𝑖 が正規分布に従わない場合にも役立つ。 𝑛 が大きければ、中心極限定理により 𝛽 ̂ 1 は近似的に正規分布に従うので、 𝛽 ̂ 1 − 𝛽 1 se ( 𝛽 ̂ 1 ) を 𝑁 ( 0 , 1 ) で近似できる。

6. 重回帰の場合

説明変数が𝑝個の重回帰

𝑌 𝑖 = 𝛽 0 + 𝛽 1 𝑥 𝑖 1 + ⋯ + 𝛽 𝑝 𝑥 𝑖 𝑝 + 𝜀 𝑖

でも、同じ形が成り立つ。

定理

𝑠 2 = 1 𝑛 − 𝑝 − 1 ∑ 𝑒 𝑖 2 , 𝛽 ̂ 𝑗 − 𝛽 𝑗 se ( 𝛽 ̂ 𝑗 ) ∼ 𝑡 ( 𝑛 − 𝑝 − 1 )

𝛽𝑗の100(1−𝛼)%信頼区間は

𝛽 ̂ 𝑗 ± 𝑡 𝑛 − 𝑝 − 1 ( 𝛼 2 ) se ( 𝛽 ̂ 𝑗 )

であり、𝑛−𝑝−1が大きければ𝑡𝑛−𝑝−1(𝛼2)を𝑧(𝛼2)で置き換えてよい。

覚え方

  • 自由度は「データ数 − 推定した係数の数（切片を含めて𝑝+1個）」。
  • se(𝛽̂𝑗)は手計算せず、ソフトウェアの出力（Std. Error）を使うのが普通。 出力の読み方は回帰係数の検定を参照。

回帰係数の検定、母平均の検定（同じ構造の𝑡統計量）、標本分布のまとめも参照。
