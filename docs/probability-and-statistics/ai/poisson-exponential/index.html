「単位時間あたり平均𝜆回、ランダムに起こる」という設定だけから、ポアソン分布と指数分布を導き、平均・分散・モーメント母関数を求める。 2つの分布の関係を図で見たい場合は、確率分布のまとめの「ポアソン過程」の節を参照のこと。

1. 設定：ポアソン過程

定義：ポアソン過程

事象が起こる時刻を早い順に0<𝑆1<𝑆2<⋯とし、時刻𝑡までに起こった事象の個数を

𝐴 ( 𝑡 ) = # { 𝑖 ≥ 1 | 𝑆 𝑖 ≤ 𝑡 }

で表す（#𝑋は集合𝑋の要素の個数）。区間(𝑠,𝑠+Δ𝑡]に起こる回数は𝐴(𝑠+Δ𝑡)−𝐴(𝑠)である。 また、事象と事象の間隔を𝑇𝑛=𝑆𝑛−𝑆𝑛−1（𝑆0=0）とする。

𝜆>0について、次の3つを満たすとき、これを発生率𝜆のポアソン過程という。

  1. 独立性：重ならない区間に起こる回数どうしは独立
  2. 定常性：𝐴(𝑠+Δ𝑡)−𝐴(𝑠)の分布は𝑠によらず、区間の長さΔ𝑡だけで決まる

  3. 稀少性：Δ𝑡→0のとき

    Pr { 𝐴 ( 𝑠 + Δ 𝑡 ) − 𝐴 ( 𝑠 ) = 1 } = 𝜆 Δ 𝑡 + 𝑜 ( Δ 𝑡 ) , Pr { 𝐴 ( 𝑠 + Δ 𝑡 ) − 𝐴 ( 𝑠 ) ≥ 2 } = 𝑜 ( Δ 𝑡 )

ここで𝑜(Δ𝑡)は、Δ𝑡→0のときΔ𝑡より速く0に近づく量（𝑜(Δ𝑡)/Δ𝑡→0）を表す。

覚え方：𝜆の意味

3つ目の条件は「短い時間 Δ 𝑡 の間に起こる確率は、時間の長さ Δ 𝑡 に比例し、その比例定数が 𝜆 」という意味である。 後で示すように 𝔼 [ 𝐴 ( 𝑡 ) ] = 𝜆 𝑡 となるので、𝜆は単位時間あたりの平均発生回数（発生率）である。 𝜆 = 1 なら長さ 1 の時間に平均 1 回、長さ 𝑇 の時間に平均 𝑇 回起こる。

2. ポアソン分布の導出

𝑃𝑘(𝑡)=Pr{𝐴(𝑡)=𝑘}とおく。

2.1. 方法1：二項分布の極限

時間[0,𝑡]を𝑛等分し、長さΔ𝑡=𝑡/𝑛の小区間𝑛個に分ける。 𝑛が十分大きければ（Δ𝑡が十分小さければ）、各小区間で起こるのは高々1回で、その確率は稀少性から𝑝=𝜆Δ𝑡=𝜆(𝑡/𝑛)（発生率 × 時間の長さ）とみなせる。 独立性・定常性から各小区間は独立な同じベルヌーイ試行なので、𝐴(𝑡)は近似的に𝐵𝑖𝑛(𝑛,𝜆(𝑡/𝑛))に従う。

𝑛が小さいと、1つの小区間に2回以上入ってしまい（赤枠）、回数を少なく数えてしまう。 しかし稀少性から、小区間に2回以上入る確率は𝑜(Δ𝑡)で、𝑛を大きくすると無視できるようになる。

𝑛Δ𝑡=𝑡に注意して𝑛→∞（すなわちΔ𝑡→0）とすると

( 𝑛 𝑘 ) 𝑝 𝑘 ( 1 − 𝑝 ) 𝑛 − 𝑘 = ( 𝑛 𝑘 ) ( 𝜆 Δ 𝑡 ) 𝑘 ( 1 − 𝜆 Δ 𝑡 ) 𝑛 − 𝑘 = 𝜆 𝑘 𝑘 ! ⋅ 𝑛 Δ 𝑡 ⋅ ( 𝑛 − 1 ) Δ 𝑡 ⋯ ( 𝑛 − 𝑘 + 1 ) Δ 𝑡 ⏟ = 𝑡 ( 𝑡 − Δ 𝑡 ) ⋯ ( 𝑡 − ( 𝑘 − 1 ) Δ 𝑡 ) ⋅ ( 1 − 𝜆 Δ 𝑡 ) 𝑛 ⋅ ( 1 − 𝜆 Δ 𝑡 ) − 𝑘 = 𝜆 𝑘 𝑘 ! ⋅ 𝑡 ( 𝑡 − Δ 𝑡 ) ⋯ ( 𝑡 − ( 𝑘 − 1 ) Δ 𝑡 ) ⏟ → 𝑡 𝑘 ⋅ ( 1 − 𝜆 Δ 𝑡 ) 𝑡 / Δ 𝑡 ⏟ → 𝑒 − 𝜆 𝑡 ⋅ ( 1 − 𝜆 Δ 𝑡 ) − 𝑘 ⏟ → 1 → ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡

となる。

覚え方

  • 極限で使ったのは(1−𝜆Δ𝑡)1/Δ𝑡→𝑒−𝜆だけ（(1+𝑥/𝑛)𝑛→𝑒𝑥で𝑥=−𝜆、𝑛=1/Δ𝑡とおいたもの）。
  • (1−𝜆Δ𝑡)𝑡/Δ𝑡は「長さ𝑡の間、どの小区間でも起こらない確率」。後で見る指数分布の方法2にまったく同じ式が出てくる。

定理

Pr { 𝐴 ( 𝑡 ) = 𝑘 } = ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡 ( 𝑘 = 0 , 1 , 2 , … )

すなわち𝐴(𝑡)∼𝑃𝑜(𝜆𝑡)。とくに長さ1の時間に起こる回数は𝑃𝑜(𝜆)に従う。

2.2. 方法2：微分方程式（別解）

時刻𝑡から𝑡+Δ𝑡の間に何回起こるかで場合分けする。独立性と稀少性から

𝑃 0 ( 𝑡 + Δ 𝑡 ) = 𝑃 0 ( 𝑡 ) ( 1 − 𝜆 Δ 𝑡 ) + 𝑜 ( Δ 𝑡 ) 𝑃 𝑘 ( 𝑡 + Δ 𝑡 ) = 𝑃 𝑘 ( 𝑡 ) ( 1 − 𝜆 Δ 𝑡 ) + 𝑃 𝑘 − 1 ( 𝑡 ) 𝜆 Δ 𝑡 + 𝑜 ( Δ 𝑡 ) ( 𝑘 ≥ 1 )

移項してΔ𝑡で割り、Δ𝑡→0とすると

𝑃 0 ′ ( 𝑡 ) = − 𝜆 𝑃 0 ( 𝑡 ) , 𝑃 𝑘 ′ ( 𝑡 ) = − 𝜆 𝑃 𝑘 ( 𝑡 ) + 𝜆 𝑃 𝑘 − 1 ( 𝑡 )

を得る。初期条件は𝑃0(0)=1、𝑃𝑘(0)=0（𝑘≥1）。

1つ目から𝑃0(𝑡)=𝑒−𝜆𝑡。 2つ目は𝑄𝑘(𝑡)=𝑒𝜆𝑡𝑃𝑘(𝑡)とおくと𝑄𝑘′=𝜆𝑄𝑘−1、𝑄0=1、𝑄𝑘(0)=0となり、順に積分して

𝑄 𝑘 ( 𝑡 ) = ( 𝜆 𝑡 ) 𝑘 𝑘 ! ⟹ 𝑃 𝑘 ( 𝑡 ) = ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡

と、方法1と同じ結果が得られる。

微分方程式𝑃𝑘′=−𝜆𝑃𝑘+𝜆𝑃𝑘−1は、「𝑘回の状態から率𝜆で出ていき（−𝜆𝑃𝑘）、𝑘−1回の状態から率𝜆で入ってくる（+𝜆𝑃𝑘−1）」という流れを表している。 最初は全員が0回（𝑃0(0)=1）にいて、時間とともに1回、2回、…へと移っていく。

3. 指数分布の導出

最初の事象が起こるまでの時間𝑇=𝑆1（=𝑇1）の分布を求める。

3.1. 方法1：ポアソン分布から

「時刻𝑡までに1回も起こらない」ことと「最初の事象が時刻𝑡より後」であることは同じ出来事なので

Pr { 𝑇 > 𝑡 } = Pr { 𝐴 ( 𝑡 ) = 0 } = 𝑒 − 𝜆 𝑡

である。したがって分布関数と確率密度関数は

𝐹 ( 𝑡 ) = 1 − 𝑒 − 𝜆 𝑡 , 𝑓 ( 𝑡 ) = 𝐹 ′ ( 𝑡 ) = 𝜆 𝑒 − 𝜆 𝑡 ( 𝑡 ≥ 0 )

左のグラフで、累計回数𝐴(𝑡)が0のままの区間（赤）の長さが、ちょうど最初の事象までの時間𝑇1である。 時刻𝑡がこの区間に入っていること（𝐴(𝑡)=0）と、𝑇1>𝑡であることは同じなので、両者の確率は等しい。

3.2. 方法2：幾何分布の極限

ポアソン分布を経由せず、ポアソン分布の方法1と同じく時間を細かく刻むことでも導ける。

時間を長さΔ𝑡の小区間に区切る。 Δ𝑡が十分小さければ、各小区間で起こるのは高々1回で、その確率は稀少性から𝑝=𝜆Δ𝑡（発生率 × 時間の長さ）とみなせる。 独立性・定常性から、各小区間は成功確率𝑝=𝜆Δ𝑡の独立なベルヌーイ試行の繰り返しになる。

最初に事象が起こる小区間より前に、事象が起こらなかった小区間の数を𝐾とすると、𝐾は幾何分布𝐺(𝜆Δ𝑡)に従う。

Pr { 𝐾 = 𝑘 } = 𝜆 Δ 𝑡 ( 1 − 𝜆 Δ 𝑡 ) 𝑘 ( 𝑘 = 0 , 1 , 2 , … )

最初の事象までの時間は𝑇≈𝐾Δ𝑡である。

「時刻𝑡までに起こらない」とは「最初の𝑡/Δ𝑡個の小区間がすべて失敗」ということなので、Δ𝑡→0とすると

Pr { 𝑇 > 𝑡 } = Pr { 𝐾 ≥ 𝑡 Δ 𝑡 } = ( 1 − 𝜆 Δ 𝑡 ) 𝑡 / Δ 𝑡 → 𝑒 − 𝜆 𝑡

となり、方法1と同じ結果が得られる。ここでも(1+𝑥/𝑛)𝑛→𝑒𝑥（𝑛=𝑡/Δ𝑡、𝑥=−𝜆𝑡）を使った。

平均と分散も、幾何分布の平均(1−𝑝)/𝑝・分散(1−𝑝)/𝑝2から極限で求まる。

𝔼 [ 𝑇 ] ≈ Δ 𝑡 𝔼 [ 𝐾 ] = Δ 𝑡 1 − 𝜆 Δ 𝑡 𝜆 Δ 𝑡 = 1 − 𝜆 Δ 𝑡 𝜆 → 1 𝜆 Var [ 𝑇 ] ≈ ( Δ 𝑡 ) 2 Var [ 𝐾 ] = ( Δ 𝑡 ) 2 1 − 𝜆 Δ 𝑡 ( 𝜆 Δ 𝑡 ) 2 = 1 − 𝜆 Δ 𝑡 𝜆 2 → 1 𝜆 2

覚え方：離散と連続の対応

離散（小区間の個数） 連続（時間）
起こりやすさ 1つの小区間で起こる確率𝑝=𝜆Δ𝑡 発生率𝜆=𝑝/Δ𝑡（単位時間あたりの平均回数）
最初の成功まで 幾何分布𝐺(𝑝) 指数分布𝐸𝑥(𝜆)
平均 (1−𝑝)/𝑝個 1/𝜆
無記憶性 Pr{𝐾≥𝑗+𝑘|𝐾≥𝑗}=Pr{𝐾≥𝑘} Pr{𝑇>𝑠+𝑡|𝑇>𝑠}=Pr{𝑇>𝑡}

指数分布は「刻み幅Δ𝑡→0の幾何分布」。無記憶性もそのまま引き継がれる。 ポアソン分布が「刻み幅Δ𝑡→0の二項分布」であることと、ちょうど対になっている。

定理

最初の事象までの時間 𝑇 は指数分布 𝐸𝑥 ( 𝜆 ) に従う。 独立性・定常性から、ある事象から次の事象までの間隔 𝑇 1 , 𝑇 2 , … も、互いに独立にそれぞれ 𝐸𝑥 ( 𝜆 ) に従う。

定理：無記憶性

𝑠,𝑡≥0について

Pr { 𝑇 > 𝑠 + 𝑡 | 𝑇 > 𝑠 } = Pr { 𝑇 > 𝑠 + 𝑡 } Pr { 𝑇 > 𝑠 } = 𝑒 − 𝜆 ( 𝑠 + 𝑡 ) 𝑒 − 𝜆 𝑠 = 𝑒 − 𝜆 𝑡 = Pr { 𝑇 > 𝑡 }

すでに𝑠だけ待っていても、そこから先の待ち時間の分布は最初と変わらない。 これはポアソン過程の独立性・定常性（過去に何が起きたかが未来に影響しない）を、時間の側から言い換えたものである。

3.3. 発展：𝑛回目までの時間とΓ分布

𝑛回目の事象が起こる時刻𝑆𝑛は、定義から𝑆𝑛=𝑇1+⋯+𝑇𝑛である。 「𝑛回目が時刻𝑡までに起こる」ことと「時刻𝑡までに𝑛回以上起こる」ことは同じなので

Pr { 𝑆 𝑛 ≤ 𝑡 } = Pr { 𝐴 ( 𝑡 ) ≥ 𝑛 } = ∑ 𝑘 = 𝑛 ∞ ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡

これを𝑡で微分すると、各項の微分

𝑑 𝑑 𝑡 [ ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡 ] = 𝜆 ( 𝜆 𝑡 ) 𝑘 − 1 ( 𝑘 − 1 ) ! 𝑒 − 𝜆 𝑡 − 𝜆 ( 𝜆 𝑡 ) 𝑘 𝑘 ! 𝑒 − 𝜆 𝑡

を足し合わせたときに隣どうしが打ち消し合い、最初の項だけが残る。

𝑓 𝑆 𝑛 ( 𝑡 ) = 𝜆 ( 𝜆 𝑡 ) 𝑛 − 1 ( 𝑛 − 1 ) ! 𝑒 − 𝜆 𝑡 = 𝜆 𝑛 Γ ( 𝑛 ) 𝑡 𝑛 − 1 𝑒 − 𝜆 𝑡

これはΓ(𝑛,𝜆)の確率密度関数であり、指数分布𝐸𝑥(𝜆)の𝑛個の和がΓ(𝑛,𝜆)になることが確かめられた。

𝑋∼𝑃𝑜(𝜆)とする。

𝔼 [ 𝑋 ] = ∑ 𝑘 = 0 ∞ 𝑘 𝜆 𝑘 𝑘 ! 𝑒 − 𝜆 = 𝜆 ∑ 𝑘 = 1 ∞ 𝜆 𝑘 − 1 ( 𝑘 − 1 ) ! 𝑒 − 𝜆 = 𝜆

4.2. モーメント母関数から求める

定理

𝑀 𝑋 ′ ( 𝜃 ) = 𝜆 𝑒 𝜃 𝑀 𝑋 ( 𝜃 ) , 𝑀 𝑋 ″ ( 𝜃 ) = ( 𝜆 𝑒 𝜃 + ( 𝜆 𝑒 𝜃 ) 2 ) 𝑀 𝑋 ( 𝜃 )

𝔼 [ 𝑋 ] = 𝑀 𝑋 ′ ( 0 ) = 𝜆 , 𝔼 [ 𝑋 2 ] = 𝑀 𝑋 ″ ( 0 ) = 𝜆 + 𝜆 2 , Var [ 𝑋 ] = 𝜆

𝑀 𝑋 1 + 𝑋 2 ( 𝜃 ) = 𝑀 𝑋 1 ( 𝜃 ) 𝑀 𝑋 2 ( 𝜃 ) = exp ( ( 𝜆 1 + 𝜆 2 ) ( 𝑒 𝜃 − 1 ) )

これは「時間𝑠の回数と、それに続く時間𝑡の回数を合わせると、時間𝑠+𝑡の回数になる」（𝑃𝑜(𝜆𝑠)と𝑃𝑜(𝜆𝑡)の和が𝑃𝑜(𝜆(𝑠+𝑡))）というポアソン過程の性質と対応している。

5. 指数分布の平均・分散

𝑇∼𝐸𝑥(𝜆)とする。

5.2. モーメント母関数から求める

定理
