1. 全体像

4つの分布は、すべて標準正規分布𝑁(0,1)から組み立てられる。

覚え方：組み立ての流れ

  1. 𝑁(0,1)を2乗して足すと𝜒2分布
  2. 𝑁(0,1)を𝜒2/ 自由度で割ると𝑡分布
  3. 𝜒2/ 自由度同士の比をとると𝐹分布
  4. 𝜒2分布はΓ分布の特別な場合

「自由度で割る」のは、平均を1にそろえて大きさを比べやすくするためと覚えるとよい（𝔼[𝜒2(𝑛)]=𝑛なので𝜒2(𝑛)/𝑛の平均は1）。

分布 作り方 平均 分散 主な用途
Γ(𝛼,𝜆) 指数分布の拡張 𝛼𝜆 𝛼𝜆2 待ち時間
𝜒2(𝑛) 𝑍12+⋯+𝑍𝑛2 𝑛 2𝑛 母分散・適合度・独立性の検定
𝑡(𝑛) 𝑍𝑋/𝑛 0 𝑛𝑛−2 母平均の検定（分散未知）
𝐹(𝑚,𝑛) 𝑋/𝑚𝑌/𝑛 𝑛𝑛−2 （略） 分散の比・分散分析・回帰

ここで𝑍,𝑍𝑖∼𝑁(0,1)、𝑋∼𝜒2(𝑚)（𝑡分布の行では𝜒2(𝑛)）、𝑌∼𝜒2(𝑛)で、すべて独立とする。 𝑡分布の分散は𝑛>2、𝐹分布の平均は𝑛>2のときに存在する。

2. Γ分布

動機：待ち時間を足し合わせたい

指数分布𝜆𝑒−𝜆𝑥は、「平均して単位時間に𝜆回起こる事象が、1回起こるまでの待ち時間」の分布だった。 では「𝛼回起こるまでの待ち時間」はどう分布するだろうか。

これは独立な指数分布𝛼個の和であり、計算すると密度は𝑥𝛼−1𝑒−𝜆𝑥に比例する形になる。 この形は𝛼が整数でなくても意味をもち、全体を1にする定数がちょうどΓ関数で書ける。 そこで𝛼を正の実数に広げたものをΓ分布と定義する。

𝛼を半整数（12,32,…）まで許しておくと、後で𝜒2分布をその特別な場合として扱えるようになる。

定義

𝛼>0、𝜆>0について、確率密度関数

𝑓 ( 𝑥 ; 𝛼 , 𝜆 ) = 𝜆 𝛼 Γ ( 𝛼 ) 𝑥 𝛼 − 1 𝑒 − 𝜆 𝑥 ( 𝑥 > 0 )

で与えられる分布をΓ分布といい、Γ(𝛼,𝜆)で表す。

定理：性質

  • 平均𝛼𝜆、分散𝛼𝜆2
  • 𝛼=1のとき指数分布𝜆𝑒−𝜆𝑥に一致する
  • 再生性：独立に𝑋1∼Γ(𝛼1,𝜆)、𝑋2∼Γ(𝛼2,𝜆)なら𝑋1+𝑋2∼Γ(𝛼1+𝛼2,𝜆)

覚え方

  • 𝛼は「何回分の待ち時間を足したか」、𝜆は「単位時間あたりに起こる回数」。 指数分布（1回分の待ち時間）を𝛼回分足したものがΓ(𝛼,𝜆)だと思えば、平均𝛼𝜆は「1回あたり1𝜆の待ち時間 × 𝛼回」として自然に出てくる。
  • Γ関数は「階乗の一般化」：Γ(𝑛+1)=𝑛!、Γ(12)=𝜋。

注意

再生性が使えるのは𝜆が等しいときだけである。

3. 𝜒2分布

動機：ばらつき・ずれの大きさを測りたい

平均は𝑋という1次式で推定でき、その分布は正規分布で済んだ。 しかし分散（ばらつき）を推定しようとすると、∑(𝑋𝑖−𝑋)2のような2乗の和が必ず出てくる。

各項を標準化すると、2乗の和は「標準正規分布に従う変数の2乗の和」になる。 そこで、この𝑍12+⋯+𝑍𝑛2の分布さえ調べておけば、母分散についての推定・検定がすべてできる。 これが𝜒2分布を定義する理由である。

同じ発想で、適合度検定や独立性の検定の「観測と期待のずれの2乗の和」も𝜒2分布で評価できる。

定義

独立な𝑍1,…,𝑍𝑛∼𝑁(0,1)について、

𝑋 = 𝑍 1 2 + 𝑍 2 2 + ⋯ + 𝑍 𝑛 2

が従う分布を自由度𝑛の𝜒2分布といい、𝜒2(𝑛)で表す。 上側100𝛼%点を𝜒𝑛2(𝛼)と書く。

定理：性質

  • 平均𝑛、分散2𝑛
  • 𝜒2(𝑛)=Γ(𝑛2,12)
  • 再生性：独立に𝑋1∼𝜒2(𝑚)、𝑋2∼𝜒2(𝑛)なら𝑋1+𝑋2∼𝜒2(𝑚+𝑛)

  • 正規母集団𝑁(𝜇,𝜎2)からの標本について、不偏分散𝑈2を使った

    ( 𝑛 − 1 ) 𝑈 2 𝜎 2 ∼ 𝜒 2 ( 𝑛 − 1 )

    が成り立つ（𝜇を𝑋で推定したぶん、自由度が1減る）。

覚え方

  • 「二乗の和」なので必ず0以上で、右に裾が長い。自由度が大きくなるほど左右対称に近づく。
  • 𝔼[𝑍𝑖2]=Var[𝑍𝑖]=1なので、𝑛個足すと平均は𝑛。「平均＝自由度」と覚える。
  • 分散は「2×自由度」。
  • 左右非対称なので、両側検定では下側と上側で別々の値（𝜒𝑛2(1−𝛼2)と𝜒𝑛2(𝛼2)）を分布表から読む。

4. 𝑡分布

動機：母分散がわからないまま平均を調べたい

母平均の推定・検定には𝑍=𝑋−𝜇𝜎/𝑛を使えばよいが、これには母標準偏差𝜎が必要である。 現実には𝜎がわかっていることはほとんどない。

そこで𝜎を標本から計算した𝑈で置き換えると、

𝑋 − 𝜇 𝑈 / 𝑛 = 𝑍 ( 𝑛 − 1 ) 𝑈 2 / 𝜎 2 𝑛 − 1

となり、分子は𝑁(0,1)、分母は𝜒2(𝑛−1)/(𝑛−1)という形になる（しかも正規母集団なら𝑋と𝑈2は独立）。 未知の𝜎は分子と分母で約分されて消えている。

そこで「𝑁(0,1)を独立な𝜒2/自由度で割ったもの」を新しい分布として定義すれば、𝜎を知らなくても母平均を扱える。 これが𝑡分布である。 ビール会社で少ない標本から品質管理をしていたゴセットが、「スチューデント」というペンネームで発表した。

定義

独立な𝑍∼𝑁(0,1)、𝑋∼𝜒2(𝑛)について、

𝑇 = 𝑍 𝑋 / 𝑛

が従う分布を自由度𝑛の𝑡分布といい、𝑡(𝑛)で表す。 上側100𝛼%点を𝑡𝑛(𝛼)と書く。

定理：性質

  • 0を中心に左右対称（𝑛>1で平均0）、𝑛>2で分散𝑛𝑛−2
  • 𝑛→∞で𝑁(0,1)に近づく

  • 正規母集団からの標本について、スチューデントの𝑡統計量

    𝑇 = 𝑋 − 𝜇 𝑈 / 𝑛 ∼ 𝑡 ( 𝑛 − 1 )
  • 𝑇∼𝑡(𝑛)なら𝑇2∼𝐹(1,𝑛)

覚え方

  • 𝑍統計量𝑋−𝜇𝜎/𝑛の𝜎を𝑈に置き換えたものが𝑡統計量。 推定した𝑈がぶれるぶん、𝑁(0,1)より裾が重い（極端な値が出やすい）。
  • そのため同じ有意水準でも𝑡𝑛(𝛼)>𝑧(𝛼)。例：𝑡15(0.025)≈2.131>1.960≈𝑧(0.025)。
  • 左右対称なので下側の点は−𝑡𝑛(𝛼)でよい。
  • 自由度が30程度を超えると、ほぼ正規分布として扱える。

5. 𝐹分布

動機：2つのばらつきを比べたい

2つの母集団のばらつきが同じかどうかを調べたい。 分散の大きさを比べるなら、差より比のほうが自然である（単位に依存せず、「何倍か」で比べられる）。

正規母集団では𝑈12=𝜎12⋅𝜒2(𝑚−1)𝑚−1、𝑈22=𝜎22⋅𝜒2(𝑛−1)𝑛−1と書けるので、比をとると

𝑈 1 2 𝑈 2 2 = 𝜎 1 2 𝜎 2 2 ⋅ 𝜒 2 ( 𝑚 − 1 ) / ( 𝑚 − 1 ) 𝜒 2 ( 𝑛 − 1 ) / ( 𝑛 − 1 )

となる。𝜎12=𝜎22なら未知の分散は約分されて消え、「𝜒2 / 自由度」同士の比だけが残る。 そこでこの比の分布を𝐹分布と定義する。

各𝜒2を自由度で割っておくのは、どちらも平均がおよそ1になり、「比が1に近いか」で判断できるようにするため。 分散分析で「群間のばらつき」と「群内のばらつき」を比べるのも同じ発想で、名前の𝐹は分散分析を考案したフィッシャー（Fisher）に由来する。

定義

独立な𝑋∼𝜒2(𝑚)、𝑌∼𝜒2(𝑛)について、

𝐹 = 𝑋 / 𝑚 𝑌 / 𝑛

が従う分布を自由度(𝑚,𝑛)の𝐹分布といい、𝐹(𝑚,𝑛)で表す。 上側100𝛼%点を𝐹𝑛𝑚(𝛼)と書く。

定理：性質

  • 必ず0以上で、右に裾が長い
  • 𝐹∼𝐹(𝑚,𝑛)なら1𝐹∼𝐹(𝑛,𝑚)

  • 上の性質から

    𝐹 𝑛 𝑚 ( 1 − 𝛼 ) = 1 𝐹 𝑚 𝑛 ( 𝛼 )

  • 正規母集団からの2標本について

    𝑈 1 2 / 𝜎 1 2 𝑈 2 2 / 𝜎 2 2 ∼ 𝐹 ( 𝑚 − 1 , 𝑛 − 1 )

覚え方

  • 「分散の比」の分布。𝜎12=𝜎22なら𝑈12/𝑈22は1の近くに来るはず。
  • 自由度は（分子の自由度, 分母の自由度）の順。分子と分母をひっくり返したら、自由度もひっくり返る。
  • 分布表には上側の点しか載っていないことが多い。下側の点は「逆数をとって自由度を入れ替える」で求める。
  • 𝑡(𝑛)2=𝐹(1,𝑛)：𝑡統計量の2乗は分子の自由度1の𝐹統計量。回帰の𝑡検定と𝐹検定が一致する理由になる。

6. どの検定でどの分布を使うか

分布 使う検定
𝑁(0,1) 母平均の検定（分散既知）、母比率の検定、母平均の差の検定（分散既知）、母比率の差の検定
𝑡分布 母平均の検定（分散未知）、母平均の差の検定（分散未知）、回帰係数の推定、回帰係数の検定
𝜒2分布 母分散の検定、適合度検定、独立性の検定
𝐹分布 母分散の比の検定、一元配置分散分析、回帰式全体の検定
