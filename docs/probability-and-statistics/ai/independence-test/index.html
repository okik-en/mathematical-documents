独立性の検定

Keywords: #統計検定, #仮説検定

目次

  1. 1. クロス表と期待度数
  2. 2. 検定統計量
  3. 3. 2×2表の簡便公式

2つの属性𝐴（𝑘個のカテゴリ𝐴1,…,𝐴𝑘）と𝐵（𝑙個のカテゴリ𝐵1,…,𝐵𝑙）について、

𝐻 0 : 𝐴 と 𝐵 は独立である

を検定する。データは𝑘×𝑙のクロス表（分割表）で与えられる。

1. クロス表と期待度数

𝐴𝑖かつ𝐵𝑗に入った観測度数を𝑂𝑖𝑗、行和を𝑂𝑖⋅、列和を𝑂⋅𝑗、総数を𝑛とする。

𝐵1 ⋯ 計
𝐴1 𝑂11 ⋯ 𝑂1⋅
⋮ ⋮ ⋮
計 𝑂⋅1 ⋯ 𝑛

𝐻0（独立）のもとでは𝑃(𝐴𝑖∩𝐵𝑗)=𝑃(𝐴𝑖)𝑃(𝐵𝑗)なので、期待度数は

𝐸 𝑖 𝑗 = 𝑛 × 𝑂 𝑖 ⋅ 𝑛 × 𝑂 ⋅ 𝑗 𝑛 = 𝑂 𝑖 ⋅ 𝑂 ⋅ 𝑗 𝑛

となる。

覚え方

期待度数は「行の合計 × 列の合計 ÷ 総数」。

2. 検定統計量

定理

𝐻0のもとで、𝑛が十分大きければ近似的に

𝜒 2 = ∑ 𝑖 = 1 𝑘 ∑ 𝑗 = 1 𝑙 ( 𝑂 𝑖 𝑗 − 𝐸 𝑖 𝑗 ) 2 𝐸 𝑖 𝑗 ∼ 𝜒 2 ( ( 𝑘 − 1 ) ( 𝑙 − 1 ) )

有意水準𝛼の棄却域は

𝜒 2 > 𝜒 ( 𝑘 − 1 ) ( 𝑙 − 1 ) 2 ( 𝛼 ) ⟹ 𝐴 と 𝐵 は独立でない（関連がある）

である（右側検定のみ）。

覚え方

  • 統計量の形は適合度検定と同じ「（観測 − 期待）² ÷ 期待」の和。
  • 自由度は（行数 − 1）×（列数 − 1）。行和と列和が固定されているので、自由に決められるマスは(𝑘−1)(𝑙−1)個しかない。
  • 2×2表なら自由度は1で、𝜒12(0.05)≈3.841（=1.962）。

3. 2×2表の簡便公式

𝐵1 𝐵2
𝐴1 𝑎 𝑏
𝐴2 𝑐 𝑑

のとき、𝑛=𝑎+𝑏+𝑐+𝑑として

𝜒 2 = 𝑛 ( 𝑎 𝑑 − 𝑏 𝑐 ) 2 ( 𝑎 + 𝑏 ) ( 𝑐 + 𝑑 ) ( 𝑎 + 𝑐 ) ( 𝑏 + 𝑑 )

例題

ある講習の受講の有無と試験の合否を調べたところ、次の結果になった。 受講と合否は独立か、有意水準5%で検定せよ。

合格 不合格 計
受講 30 20 50
未受講 20 30 50
計 50 50 100

期待度数はすべて50×50/100=25なので

𝜒 2 = 5 2 + 5 2 + 5 2 + 5 2 25 = 4.0

簡便公式でも100(30×30−20×20)250×50×50×50=4.0となる。

自由度1で𝜒12(0.05)≈3.841。4.0>3.841なので𝐻0を棄却し、受講と合否には関連があると判断する（𝑝≈0.046）。

注意

  • 各期待度数が5以上あることが目安。
  • 2×2表で度数が少ないときは、|𝑎𝑑−𝑏𝑐|から𝑛/2を引いてから2乗するイェーツの補正を使うことがある。
  • 「独立でない」とわかっても、因果関係があるとは限らない。
