母平均の検定

Keywords: #統計検定, #仮説検定

目次

  1. 1. 母分散が既知のとき（𝑍検定）
  2. 2. 母分散が未知のとき（𝑡検定）
  3. 3. 信頼区間との関係

正規母集団𝑁(𝜇,𝜎2)から大きさ𝑛の無作為標本𝑋1,…,𝑋𝑛をとり、母平均𝜇について

𝐻 0 : 𝜇 = 𝜇 0

を検定する。

使う統計量は、母分散𝜎2が既知か未知かで変わる。

1. 母分散が既知のとき（𝑍検定）

定理

𝐻0:𝜇=𝜇0のもとで

𝑍 = 𝑋 − 𝜇 0 𝜎 / 𝑛 ∼ 𝑁 ( 0 , 1 )

有意水準𝛼の棄却域は次のとおり。

両側検定
|𝑍|>𝑧(𝛼2)⟹𝜇≠𝜇0
右側検定
𝑍>𝑧(𝛼)⟹𝜇>𝜇0
左側検定
𝑍<−𝑧(𝛼)⟹𝜇<𝜇0

例題

𝑁 ( 𝜇 , 5 2 ) から 𝑛 = 25 の標本をとったところ、 𝑥 = 52 だった。 𝐻 0 : 𝜇 = 50 、 𝐻 1 : 𝜇 ≠ 50 を有意水準 5 % で検定せよ。
𝑧 = 52 − 50 5 / 25 = 2 1 = 2.0

|𝑧|=2.0>1.96=𝑧(0.025)なので、𝐻0を棄却する（𝑝≈0.046）。

2. 母分散が未知のとき（𝑡検定）

𝜎がわからないので、代わりに不偏分散

𝑈 2 = 1 𝑛 − 1 ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝑋 ) 2

の平方根𝑈を使う。

定理

𝐻0:𝜇=𝜇0のもとで

𝑇 = 𝑋 − 𝜇 0 𝑈 / 𝑛 ∼ 𝑡 ( 𝑛 − 1 )

有意水準𝛼の棄却域は次のとおり。

両側検定
|𝑇|>𝑡𝑛−1(𝛼2)⟹𝜇≠𝜇0
右側検定
𝑇>𝑡𝑛−1(𝛼)⟹𝜇>𝜇0
左側検定
𝑇<−𝑡𝑛−1(𝛼)⟹𝜇<𝜇0

例題

正規母集団から 𝑛 = 16 の標本をとったところ、 𝑥 = 10.6 、 𝑢 = 1.2 だった。 𝐻 0 : 𝜇 = 10 を有意水準 5 % で、(a) 両側検定、(b) 右側検定せよ。
𝑡 = 10.6 − 10 1.2 / 16 = 0.6 0.3 = 2.0

自由度は𝑛−1=15である。

  1. 両側：𝑡15(0.025)≈2.131で、|𝑡|=2.0<2.131なので𝐻0を棄却しない（𝑝≈0.064）。
  2. 右側：𝑡15(0.05)≈1.753で、𝑡=2.0>1.753なので𝐻0を棄却する（𝑝≈0.032）。

同じデータでも、両側か片側かで結論が変わりうることに注意。

覚え方

  • 形はどちらも標本平均−仮説の値標準誤差。 分母の𝜎を𝑈に置き換えたら、𝑁(0,1)を𝑡(𝑛−1)に置き換える。
  • 自由度が𝑛−1なのは、𝑈2の計算で𝜇の代わりに𝑋を使ったから。
  • 𝑛が大きい（目安𝑛≥30）ときは、𝜎が未知でも𝑡(𝑛−1)≈𝑁(0,1)として𝑍検定で近似することが多い。

注意

  • 統計量で使うのは不偏分散𝑈2（𝑛−1で割る）。𝑛で割った標本分散𝑆2が与えられた場合は𝑈2=𝑛𝑛−1𝑆2に直してから使う。
  • 母集団が正規分布でない場合でも、𝑛が大きければ中心極限定理により𝑍検定で近似できる。

3. 信頼区間との関係

有意水準𝛼の両側検定で𝐻0:𝜇=𝜇0が棄却されないことと、𝜇0が100(1−𝛼)%信頼区間

𝑋 − 𝑡 𝑛 − 1 ( 𝛼 2 ) 𝑈 𝑛 ≤ 𝜇 ≤ 𝑋 + 𝑡 𝑛 − 1 ( 𝛼 2 ) 𝑈 𝑛

に含まれることは同値である。

覚え方

「信頼区間に入っていれば棄却しない、外れていれば棄却する」。 区間推定の問題と検定の問題は、同じ式の裏表である（信頼区間も参照）。
