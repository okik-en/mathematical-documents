母平均の差の検定

Keywords: #統計検定, #仮説検定

目次

  1. 1. 母分散が既知のとき
  2. 2. 母分散が未知で等しいとき
  3. 3. 母分散が未知で等しいとは限らないとき（ウェルチの検定）
  4. 4. 対応のある2標本

2つの正規母集団𝑁(𝜇1,𝜎12)、𝑁(𝜇2,𝜎22)から、それぞれ大きさ𝑚、𝑛の独立な標本𝑋1,…,𝑋𝑚と𝑌1,…,𝑌𝑛をとる。 標本平均を𝑋、𝑌、不偏分散を𝑈12、𝑈22とし、

𝐻 0 : 𝜇 1 = 𝜇 2

を検定する。

使う統計量は、母分散について何がわかっているかで3通りに分かれる。

覚え方：場合分け

  1. 母分散𝜎12,𝜎22が既知 → 𝑍検定
  2. 母分散は未知だが等しい（𝜎12=𝜎22） → プールした分散による𝑡検定
  3. 母分散は未知で等しいとは限らない → ウェルチの𝑡検定

どれも形は𝑋−𝑌標準誤差で、分母の作り方だけが違う。

棄却域はいずれも、統計量を𝑆、その分布の上側点を𝑐(𝛼)として

両側検定
|𝑆|>𝑐(𝛼2)⟹𝜇1≠𝜇2
右側検定
𝑆>𝑐(𝛼)⟹𝜇1>𝜇2
左側検定
𝑆<−𝑐(𝛼)⟹𝜇1<𝜇2

の形になる。

1. 母分散が既知のとき

定理

𝐻0:𝜇1=𝜇2のもとで

𝑍 = 𝑋 − 𝑌 𝜎 1 2 / 𝑚 + 𝜎 2 2 / 𝑛 ∼ 𝑁 ( 0 , 1 )

𝑋−𝑌は正規分布の再生性から𝑁(𝜇1−𝜇2,𝜎12/𝑚+𝜎22/𝑛)に従う。 独立な確率変数の差の分散は分散の和となる点に注意。

2. 母分散が未知で等しいとき

共通の母分散𝜎2を、2つの標本をまとめて推定する。

定義：プールした分散

𝑈 2 = ( 𝑚 − 1 ) 𝑈 1 2 + ( 𝑛 − 1 ) 𝑈 2 2 𝑚 + 𝑛 − 2

定理

𝜎12=𝜎22かつ𝐻0:𝜇1=𝜇2のもとで

𝑇 = 𝑋 − 𝑌 𝑈 1 𝑚 + 1 𝑛 ∼ 𝑡 ( 𝑚 + 𝑛 − 2 )

覚え方

  • 𝑈2は2つの不偏分散を自由度で重みづけした平均。
  • 自由度は(𝑚−1)+(𝑛−1)=𝑚+𝑛−2。各標本で平均を1つずつ推定したぶん、2減る。

例題

𝑚 = 10 、 𝑥 = 23.0 、 𝑢 1 2 = 4.0 と、 𝑛 = 12 、 𝑦 = 21.0 、 𝑢 2 2 = 5.0 の2標本がある。 母分散が等しいと仮定して、 𝐻 0 : 𝜇 1 = 𝜇 2 を有意水準 5 % で両側検定せよ。
𝑢 2 = 9 × 4.0 + 11 × 5.0 20 = 91 20 = 4.55 𝑡 = 23.0 − 21.0 4.55 1 10 + 1 12 ≈ 2.0 2.133 × 0.428 ≈ 2.19

𝑡20(0.025)≈2.086で、2.19>2.086なので𝐻0を棄却する（𝑝≈0.041）。

3. 母分散が未知で等しいとは限らないとき（ウェルチの検定）

定理

𝐻0:𝜇1=𝜇2のもとで、近似的に

𝑇 = 𝑋 − 𝑌 𝑈 1 2 / 𝑚 + 𝑈 2 2 / 𝑛 ∼ 𝑡 ( 𝑘 )

ここで𝑘は次の𝑐に最も近い整数である。

𝑐 = ( 𝑈 1 2 / 𝑚 + 𝑈 2 2 / 𝑛 ) 2 ( 𝑈 1 2 / 𝑚 ) 2 𝑚 − 1 + ( 𝑈 2 2 / 𝑛 ) 2 𝑛 − 1

覚え方

  • 分子・分母は「分散既知の𝑍検定」の𝜎2を𝑈2に置き換えただけ。
  • 自由度𝑐の式は覚えにくいが、試験では「与えられた式に代入する」形で出ることが多い。 𝑐はmin(𝑚,𝑛)−1以上𝑚+𝑛−2以下に収まる。
  • 実務では、等分散かどうかわからないときはウェルチの検定を使うのが一般的。

上の例題のデータにウェルチの検定を使うと、

𝑡 = 2.0 4.0 / 10 + 5.0 / 12 ≈ 2.0 0.904 ≈ 2.21 , 𝑐 ≈ 19.87

より自由度20の𝑡分布を使い、2.21>2.086なので𝐻0を棄却する。

4. 対応のある2標本

同じ人の「薬の投与前と投与後」のように、2つの標本がペアになっている場合は、ペアごとの差𝐷𝑖=𝑋𝑖−𝑌𝑖（𝑖=1,…,𝑛）をとり、1標本の母平均の検定に帰着させる。

定理

差𝐷𝑖が正規分布𝑁(𝜇𝐷,𝜎𝐷2)に従うとき、𝐻0:𝜇𝐷=0のもとで

𝑇 = 𝐷 𝑈 𝐷 / 𝑛 ∼ 𝑡 ( 𝑛 − 1 )

ここで𝐷、𝑈𝐷2は差𝐷𝑖の標本平均と不偏分散。

例題

9 人について投与前後の値の差をとったところ、 𝑑 = 1.5 、 𝑢 𝐷 = 2.0 だった。 効果があるか（ 𝐻 1 : 𝜇 𝐷 > 0 ）、有意水準 5 % で検定せよ。
𝑡 = 1.5 2.0 / 9 = 2.25

𝑡8(0.05)≈1.860で、2.25>1.860なので𝐻0を棄却し、効果があると判断する。

注意

対応のあるデータを、対応のない2標本として検定してはいけない。 個人差が分散に含まれてしまい、検出力が大きく下がる。 「同じ対象を2回測っているか」を必ず確認すること。

母分散の比の検定（等分散かどうかの確認）、標本分布（2標本問題の導出）も参照。
