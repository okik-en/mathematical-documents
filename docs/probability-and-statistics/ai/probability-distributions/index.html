2. 離散型の分布

2.1. ベルヌーイ分布

動機：すべての離散分布の部品

コイン投げの表・裏、製品の良・不良、賛成・反対など、結果が2通りしかない試行はいたるところにある。 これを「成功なら 1 、失敗なら 0 」という確率変数で表しておけば、成功の回数は単に足し算で数えられる。 二項分布・幾何分布・負の二項分布は、すべてこのベルヌーイ試行を繰り返して作られる。

定義

Pr { 𝑋 = 1 } = 𝑝 , Pr { 𝑋 = 0 } = 1 − 𝑝

このような確率変数𝑋の分布をベルヌーイ分布という。

定理：性質

平均は 𝑝 、分散は 𝑝 ( 1 − 𝑝 ) である。

覚え方

  • 𝑋2=𝑋（0と1しかとらない）なので𝔼[𝑋2]=𝑝。よってVar[𝑋]=𝑝−𝑝2=𝑝(1−𝑝)。
  • 分散𝑝(1−𝑝)は𝑝=12のとき最大の14。「五分五分のときが一番ばらつく」。

2.2. 二項分布

動機：成功回数を数えたい

成功確率 𝑝 の試行を 𝑛 回独立に繰り返したときの成功回数を知りたい。 これは独立なベルヌーイ確率変数 𝑛 個の和であり、その分布が二項分布である。 世論調査で「 𝑛 人中何人が賛成か」を考えるときの基本モデルになる。

定義

Pr { 𝑋 = 𝑘 } = ( 𝑛 𝑘 ) 𝑝 𝑘 ( 1 − 𝑝 ) 𝑛 − 𝑘 ( 𝑘 = 0 , 1 , … , 𝑛 )

で与えられる分布を二項分布といい、𝐵𝑖𝑛(𝑛,𝑝)で表す。

定理：性質

  • 平均𝑛𝑝、分散𝑛𝑝(1−𝑝)
  • 再生性：独立に𝑋1∼𝐵𝑖𝑛(𝑚,𝑝)、𝑋2∼𝐵𝑖𝑛(𝑛,𝑝)なら𝑋1+𝑋2∼𝐵𝑖𝑛(𝑚+𝑛,𝑝)
  • 𝑛が大きいとき、𝑁(𝑛𝑝,𝑛𝑝(1−𝑝))で近似できる（目安：𝑛𝑝≥5かつ𝑛(1−𝑝)≥5）
  • 𝑛→∞、𝑝→0（𝑛𝑝=𝜆は一定）の極限で𝑃𝑜(𝜆)に近づく

覚え方

  • (𝑛𝑘)は「𝑛回のうちどの𝑘回が成功か」の選び方、𝑝𝑘(1−𝑝)𝑛−𝑘は「その並び1通りの確率」。
  • 平均・分散はベルヌーイ分布の𝑛倍。独立な和なので、平均も分散も足し算になる。

2.3. ポアソン分布

動機：「稀だが試行回数が多い」事象を数えたい

1日の交通事故の件数や、1ページあたりの誤植の数を考える。 事故が起こりうる機会は膨大だが、1回あたりの確率はとても小さい。 これは二項分布𝐵𝑖𝑛(𝑛,𝑝)で𝑛を非常に大きく、𝑝を非常に小さくした状況で、𝑛も𝑝も正確にはわからない。

そこで平均回数𝜆=𝑛𝑝だけを固定して𝑛→∞の極限をとると、𝑛と𝑝が消えて𝜆だけで書ける分布が得られる。 これがポアソン分布である。

定義

Pr { 𝑋 = 𝑘 } = 𝜆 𝑘 𝑒 − 𝜆 𝑘 ! ( 𝑘 = 0 , 1 , 2 , … )

で与えられる分布をポアソン分布といい、𝑃𝑜(𝜆)で表す。

定理：性質

  • 平均＝分散＝𝜆
  • 再生性：独立に𝑋1∼𝑃𝑜(𝜆1)、𝑋2∼𝑃𝑜(𝜆2)なら𝑋1+𝑋2∼𝑃𝑜(𝜆1+𝜆2)
  • 𝜆が大きいとき、𝑁(𝜆,𝜆)で近似できる

覚え方

  • 二項分布の分散𝑛𝑝(1−𝑝)で𝑝→0とすると𝑛𝑝=𝜆。だから平均も分散も𝜆。
  • 「1時間に平均3件なら、2時間では平均6件」というように、時間を伸ばすと𝜆も比例して増える（再生性）。
  • 二項近似の目安：𝑛≥50程度で𝑝≤0.1程度。

2.4. 幾何分布

動機：初めて成功するまで待ちたい

「当たりが出るまでくじを引き続ける」とき、何回はずれるかを知りたい。 二項分布は「回数を決めて成功を数える」のに対し、幾何分布は「成功するまで続けて失敗を数える」という、視点を逆にした分布である。

定義

成功確率𝑝のベルヌーイ試行を繰り返し、初めて成功するまでの失敗の回数を𝑋とするとき、

Pr { 𝑋 = 𝑘 } = 𝑝 ( 1 − 𝑝 ) 𝑘 ( 𝑘 = 0 , 1 , 2 , … )

この分布を幾何分布といい、𝐺(𝑝)で表す。

定理：性質

  • 平均1−𝑝𝑝、分散1−𝑝𝑝2
  • 無記憶性：Pr{𝑋≥𝑠+𝑡|𝑋≥𝑠}=Pr{𝑋≥𝑡}

覚え方

  • 確率が𝑝,𝑝(1−𝑝),𝑝(1−𝑝)2,…と等比数列（幾何数列）で減るから「幾何」分布。
  • 成功確率16なら、平均5回はずれてから当たる（試行回数で数えれば平均6回目）。「平均1𝑝回目に成功」と覚えるとよい。
  • 無記憶性：「10回はずれた後でも、これから先の待ち回数の分布は最初と同じ」。くじに記憶はない。

注意：定義の流儀

「初めて成功するまでの試行回数」 𝑌 = 𝑋 + 1 （ 𝑌 = 1 , 2 , … ）で定義する本もある。 その場合 Pr { 𝑌 = 𝑘 } = 𝑝 ( 1 − 𝑝 ) 𝑘 − 1 、平均 1 𝑝 で、分散は同じ 1 − 𝑝 𝑝 2 。 問題文でどちらの定義かを必ず確認すること。

2.5. 負の二項分布

動機：𝑟回成功するまで待ちたい

幾何分布は「1回目の成功」までだった。これを「𝑟回目の成功」まで待つように一般化したい。 𝑟 回目の成功までの失敗回数は、「各成功までの失敗回数（幾何分布）」を 𝑟 個足したものになる。

定義

成功確率𝑝のベルヌーイ試行を繰り返し、𝑟回目の成功までの失敗の回数を𝑋とするとき、

Pr { 𝑋 = 𝑘 } = ( 𝑟 + 𝑘 − 1 𝑘 ) 𝑝 𝑟 ( 1 − 𝑝 ) 𝑘 ( 𝑘 = 0 , 1 , 2 , … )

この分布を負の二項分布といい、𝑁𝐵(𝑟,𝑝)で表す。

定理：性質

  • 平均𝑟(1−𝑝)𝑝、分散𝑟(1−𝑝)𝑝2
  • 𝑟=1のとき幾何分布に一致する
  • 独立な𝐺(𝑝)を𝑟個足すと𝑁𝐵(𝑟,𝑝)

覚え方

  • 平均・分散は幾何分布の𝑟倍（独立な𝑟個の和だから）。
  • (𝑟+𝑘−1𝑘)は「最後の1回は必ず成功なので、それ以外の𝑟+𝑘−1回のうちどの𝑘回が失敗か」。
  • 名前の由来：負の指数(1−𝑞)−𝑟へ拡張した二項定理の展開に確率が現れることから。

2.6. 超幾何分布

動機：取り出したものを戻さない

𝑁 個のうち 𝑀 個が当たりの箱から 𝑛 個を取り出すとき、当たりの数を知りたい。 取り出すたびに戻す（復元抽出）なら毎回の確率は 𝑀 𝑁 で一定なので二項分布になる。 しかし現実の抜き取り検査や世論調査では、同じものを2回選ばない（非復元抽出）。 その正確な分布が超幾何分布である。

定義

Pr { 𝑋 = 𝑘 } = ( 𝑀 𝑘 ) ( 𝑁 − 𝑀 𝑛 − 𝑘 ) ( 𝑁 𝑛 )

で与えられる分布を超幾何分布といい、Hyper(𝑁,𝑀,𝑛)で表す。

定理：性質

𝑝=𝑀𝑁とおくと

  • 平均𝑛𝑝
  • 分散𝑛𝑝(1−𝑝)⋅𝑁−𝑛𝑁−1
  • 𝑁→∞（𝑀𝑁=𝑝一定）のとき𝐵𝑖𝑛(𝑛,𝑝)に近づく

覚え方

  • 平均は二項分布と同じ𝑛𝑝。
  • 分散は二項分布に𝑁−𝑛𝑁−1（有限母集団修正）がかかって小さくなる。戻さないぶん、同じものを重複して数えず、ばらつきが減るから。 詳しくは有限母集団修正を参照。
  • 母集団𝑁が標本𝑛に比べて十分大きければ、戻しても戻さなくてもほぼ同じなので二項分布で近似できる。

3. 連続型の分布

3.1. 一様分布

動機：「どこでも同じ」を表したい

ルーレットの止まる角度や、四捨五入による丸め誤差のように、区間内のどの値も同じ程度に起こりやすい状況を表したい。 何の情報もないときの最も素朴なモデルでもあり、コンピュータで乱数を作るときの出発点にもなる。

定義

𝑓 ( 𝑥 ) = 1 𝑏 − 𝑎 ( 𝑎 ≤ 𝑥 ≤ 𝑏 )

で与えられる分布を一様分布といい、𝑈(𝑎,𝑏)で表す。

定理：性質

平均は 𝑎 + 𝑏 2 、分散は ( 𝑏 − 𝑎 ) 2 12 である。

覚え方

  • 平均は区間の真ん中。
  • 分散の「12」は𝑈(0,1)の分散∫01𝑥2𝑑𝑥−(12)2=13−14=112から来ている。
  • 離散版（サイコロの目など）を離散一様分布という。1,…,𝑛の一様分布の平均は𝑛+12、分散は𝑛2−112。

3.2. 指数分布

動機：次に起こるまでの時間を測りたい

ポアソン分布は「一定時間に何回起こるか」を数えた。 同じ現象を「次に起こるまでどれだけ待つか」という時間の側から見たものが指数分布である。

単位時間あたり平均𝜆回起こるとき、時間𝑥の間に1回も起こらない確率は、ポアソン分布𝑃𝑜(𝜆𝑥)で0回の確率𝑒−𝜆𝑥。 これが「待ち時間が𝑥を超える確率」Pr{𝑋>𝑥}なので、微分すると密度𝜆𝑒−𝜆𝑥が得られる。

定義

𝑓 ( 𝑥 ) = 𝜆 𝑒 − 𝜆 𝑥 ( 𝑥 ≥ 0 )

で与えられる分布を指数分布といい、𝐸𝑥(𝜆)で表す。

定理：性質

  • 平均1𝜆、分散1𝜆2
  • Pr{𝑋>𝑥}=𝑒−𝜆𝑥
  • 無記憶性：Pr{𝑋>𝑠+𝑡|𝑋>𝑠}=Pr{𝑋>𝑡}
  • 独立な𝐸𝑥(𝜆)を𝛼個足すとΓ(𝛼,𝜆)

覚え方

  • 「1時間に平均𝜆回」なら「平均1𝜆時間ごと」。平均は𝜆の逆数。
  • 標準偏差1𝜆が平均と等しい。
  • 無記憶性：「10分待っても来ないバスは、あと何分待つかの分布が最初と同じ」。連続型で無記憶性をもつのは指数分布だけで、幾何分布の連続版にあたる。
  • 機械の故障までの時間や、窓口に客が来る間隔のモデルに使われる。

3.3. 正規分布

動機：多数の小さな要因の和

身長や測定誤差は、無数の小さな要因が足し合わさって決まる。 中心極限定理によれば、独立な確率変数をたくさん足すと、元の分布によらず和の分布はある決まった形に近づく。 その「行き着く先」が正規分布であり、だからこそ自然界や統計の至るところに現れる。 標本平均の分布が近似的に正規分布になることも、ここから説明できる。

定義

𝑓 ( 𝑥 ) = 1 2 𝜋 𝜎 exp ( − ( 𝑥 − 𝜇 ) 2 2 𝜎 2 )

で与えられる分布を正規分布といい、𝑁(𝜇,𝜎2)で表す。 𝑁(0,1)を標準正規分布という。

定理：性質

  • 平均𝜇、分散𝜎2。𝜇を中心に左右対称
  • 標準化：𝑋∼𝑁(𝜇,𝜎2)なら𝑍=𝑋−𝜇𝜎∼𝑁(0,1)
  • 再生性：独立に𝑋𝑖∼𝑁(𝜇𝑖,𝜎𝑖2)なら𝑎𝑋1+𝑏𝑋2∼𝑁(𝑎𝜇1+𝑏𝜇2,𝑎2𝜎12+𝑏2𝜎22)
  • 標本平均：𝑁(𝜇,𝜎2)からの大きさ𝑛の標本について𝑋∼𝑁(𝜇,𝜎2/𝑛)

覚え方

  • 𝜇±𝜎に約68%、𝜇±2𝜎に約95%、𝜇±3𝜎に約99.7%が入る。
  • 正確には95%は𝜇±1.96𝜎。
  • 差𝑋1−𝑋2の分散も足し算𝜎12+𝜎22になる（(−1)2=1なので）。
  • 二項分布・ポアソン分布・𝑡分布など、多くの分布が極限で正規分布に近づく。

3.4. 2変量正規分布

動機：2つの量の関係ごと表したい

身長と体重のように、2つの量が互いに関係しながらばらつく状況を表したい。 それぞれが正規分布に従うだけでなく、その「連動の強さ」まで含めたモデルが2変量正規分布である。 回帰分析や相関係数の理論の土台になる。

定義

(𝑋,𝑌)が平均(𝜇𝑋,𝜇𝑌)、分散𝜎𝑋2,𝜎𝑌2、相関係数𝜌の2変量正規分布に従うとき、その同時確率密度関数は

𝑓 ( 𝑥 , 𝑦 ) = 1 2 𝜋 𝜎 𝑋 𝜎 𝑌 1 − 𝜌 2 exp [ − 1 2 ( 1 − 𝜌 2 ) { ( 𝑥 − 𝜇 𝑋 𝜎 𝑋 ) 2 − 2 𝜌 𝑥 − 𝜇 𝑋 𝜎 𝑋 𝑦 − 𝜇 𝑌 𝜎 𝑌 + ( 𝑦 − 𝜇 𝑌 𝜎 𝑌 ) 2 } ]

定理：性質

  • 周辺分布はそれぞれ正規分布：𝑋∼𝑁(𝜇𝑋,𝜎𝑋2)、𝑌∼𝑁(𝜇𝑌,𝜎𝑌2)
  • 共分散Cov[𝑋,𝑌]=𝜌𝜎𝑋𝜎𝑌
  • 𝑋と𝑌が独立 ⟺ 𝜌=0

  • 条件付き分布も正規分布：

    𝑌 | 𝑋 = 𝑥 ∼ 𝑁 ( 𝜇 𝑌 + 𝜌 𝜎 𝑌 𝜎 𝑋 ( 𝑥 − 𝜇 𝑋 ) , 𝜎 𝑌 2 ( 1 − 𝜌 2 ) )

覚え方

  • 条件付き平均𝜇𝑌+𝜌𝜎𝑌𝜎𝑋(𝑥−𝜇𝑋)は、まさに回帰直線。𝑥がわかると𝑦の予測は平均から𝜌倍だけ寄せて動く（平均への回帰）。
  • 条件付き分散𝜎𝑌2(1−𝜌2)は、𝑥を知ったことで分散が(1−𝜌2)倍に減ることを表す。𝜌2は決定係数。
  • 一般には「無相関でも独立とは限らない」が、2変量正規分布では無相関なら独立。ここはよく問われる。

4. ポアソン過程：ポアソン分布と指数分布の関係

ポアソン分布と指数分布は、同じ現象を「回数」と「時間」の両側から見たものである。 事象が単位時間あたり平均𝜆回、互いに独立かつランダムに起こる状況をポアソン過程という（客の到着、電話の着信など）。 この設定からポアソン分布・指数分布を導出し、平均・分散・モーメント母関数を求める計算はポアソン分布と指数分布の導出にまとめてある。

時間軸上の黒い点が、事象の起こった時刻である。同じ点の列から

  1. 長さ1の区間に区切って、区間ごとに何回起こったかを数えると、その回数はポアソン分布𝑃𝑜(𝜆)に従う
  2. 点と点の間隔の長さを測ると、その長さは指数分布𝐸𝑥(𝜆)に従う

右側のグラフは、左の図から実際に数えた回数と、測った間隔の長さを集計したもの（棒）で、理論上の分布（点・曲線）とおおむね一致している。

赤に注目すると、0回の区間（[1,2)、[5,6)、[8,9)）には、それぞれその区間を丸ごと含む長い間隔がある。「区間で0回」ということは「その区間をまたぐ長さ1以上の間隔がある」ということと同じである。 このように、回数が少ないことと間隔が長いことは同じ出来事の言い換えになっている。 理論上も、𝑃𝑜(1)で0回の確率と、𝐸𝑥(1)で間隔が1より長い確率は、どちらも𝑒−1≈0.37で等しい。

次の図は、同じ関係を累計回数のグラフで表し、さらに待ち行列への応用まで描いたものである。

定理：回数と間隔

単位時間あたり平均𝜆回のポアソン過程について、

  • 時刻𝑡までの発生回数𝐴(𝑡)は𝑃𝑜(𝜆𝑡)に従う
  • 発生の間隔𝑇1,𝑇2,…は互いに独立で、いずれも𝐸𝑥(𝜆)に従う
  • 𝑛回目の発生時刻𝑆𝑛=𝑇1+⋯+𝑇𝑛はΓ(𝑛,𝜆)に従う

この2つが表裏一体であることは、「時刻𝑡までに1回も起こらない」という同じ出来事を2通りに書くとわかる。

Pr { 𝐴 ( 𝑡 ) = 0 } = 𝑒 − 𝜆 𝑡 = Pr { 𝑇 1 > 𝑡 }

左辺はポアソン分布𝑃𝑜(𝜆𝑡)で0回の確率、右辺は指数分布𝐸𝑥(𝜆)で待ち時間が𝑡を超える確率である。 一般に「時刻𝑡までに𝑛回以上起こる」ことと「𝑛回目が時刻𝑡までに起こる」ことは同じなので

Pr { 𝐴 ( 𝑡 ) ≥ 𝑛 } = Pr { 𝑆 𝑛 ≤ 𝑡 }

が成り立ち、ポアソン分布とΓ分布もこの式で結ばれる。

覚え方

  • 数えればポアソン、測れば指数。
  • グラフの縦方向（ある時刻での高さ）を見ればポアソン分布、横方向（段と段の間の長さ）を見れば指数分布。
  • 指数分布の無記憶性により、どの時点から観察を始めても「次の発生までの時間」は同じ𝐸𝑥(𝜆)に従う。

4.1. 応用：M/M/1待ち行列

窓口が1つの待ち行列で、客の到着が率𝜆のポアソン過程、1人あたりのサービス時間が率𝜇の指数分布に従うモデルをM/M/1モデルという。 到着で系内人数𝑁(𝑡)が1増え、サービス完了で1減る（図の下段）。

定理

𝜌=𝜆𝜇<1のとき、十分時間が経つと系内人数𝑁の分布は

Pr { 𝑁 = 𝑛 } = ( 1 − 𝜌 ) 𝜌 𝑛 ( 𝑛 = 0 , 1 , 2 , … )

となる。これは成功確率1−𝜌の幾何分布𝐺(1−𝜌)であり、平均系内人数は𝜌1−𝜌。

覚え方

  • 𝜌=𝜆𝜇は窓口の混み具合（利用率）。𝜌が1に近づくと平均系内人数𝜌1−𝜌は急激に大きくなる。
  • 「𝑛人いる確率」が𝜌倍ずつ等比数列で減っていくので幾何分布になる。
