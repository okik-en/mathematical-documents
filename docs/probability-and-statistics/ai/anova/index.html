一元配置分散分析

3つ以上の群（処理）の母平均に差があるかを、まとめて検定する方法。 1つの要因（因子）の水準だけを変える実験を一元配置実験という。

1. 設定

𝑘個の群があり、第𝑖群から𝑛𝑖個のデータ𝑦𝑖1,…,𝑦𝑖𝑛𝑖をとる。総数を𝑁=𝑛1+⋯+𝑛𝑘とする。

定義：モデル

𝑦 𝑖 𝑗 = 𝜇 𝑖 + 𝜀 𝑖 𝑗 , 𝜀 𝑖 𝑗 ∼ 𝑁 ( 0 , 𝜎 2 ) （独立）

各群の分散は等しいと仮定する。

検定する仮説は

𝐻 0 : 𝜇 1 = 𝜇 2 = ⋯ = 𝜇 𝑘 𝐻 1 : 少なくとも1組の 𝜇 𝑖 が異なる

である。

2. 平方和の分解

第𝑖群の平均を𝑦𝑖、全体の平均を𝑦とする。

定理：変動の分解

∑ 𝑖 , 𝑗 ( 𝑦 𝑖 𝑗 − 𝑦 ) 2 ⏟ 𝑆 𝑇 （総平方和） = ∑ 𝑖 𝑛 𝑖 ( 𝑦 𝑖 − 𝑦 ) 2 ⏟ 𝑆 𝐴 （群間平方和） + ∑ 𝑖 , 𝑗 ( 𝑦 𝑖 𝑗 − 𝑦 𝑖 ) 2 ⏟ 𝑆 𝐸 （群内平方和）

覚え方

  • 全体のばらつき ＝ 群の違いによるばらつき ＋ 群の中の誤差によるばらつき。
  • 群間の差が誤差に比べて大きければ、「群によって平均が違う」と考えられる。

3. 𝐹検定と分散分析表

各平方和を自由度で割ったものを平均平方（不偏分散）という。

要因 平方和 自由度 平均平方 𝐹比
群間 𝑆𝐴 𝑘−1 𝑉𝐴=𝑆𝐴/(𝑘−1) 𝑉𝐴/𝑉𝐸
群内（誤差） 𝑆𝐸 𝑁−𝑘 𝑉𝐸=𝑆𝐸/(𝑁−𝑘)
全体 𝑆𝑇 𝑁−1

定理

𝐻0のもとで

𝐹 = 𝑉 𝐴 𝑉 𝐸 ∼ 𝐹 ( 𝑘 − 1 , 𝑁 − 𝑘 )

𝐹>𝐹𝑁−𝑘𝑘−1(𝛼)なら𝐻0を棄却する（右側検定のみ）。

覚え方

  • 𝑉𝐸は𝐻0が正しくても間違っていても𝜎2の推定量。𝑉𝐴は𝐻0が正しいときだけ𝜎2の推定量になり、平均に差があると大きくなる。 だから𝐹比が大きいときだけ棄却する。
  • 自由度：群間は「群の数 − 1」、群内は「総数 − 群の数」。足すと全体の𝑁−1になる。
  • 分散分析表は、空欄を埋める問題が定番。平方和も自由度も足し算が成り立つことを使う。

例題

3 つの群に各 5 人ずつ（ 𝑁 = 15 ）を割り当てて実験し、 𝑆 𝐴 = 40 、 𝑆 𝐸 = 60 を得た。 有意水準 5 % で 𝐻 0 : 𝜇 1 = 𝜇 2 = 𝜇 3 を検定せよ。
要因 平方和 自由度 平均平方 𝐹比
群間 40 2 20 4.0
群内 60 12 5
全体 100 14

𝐹122(0.05)≈3.885で、4.0>3.885なので𝐻0を棄却する（𝑝≈0.047）。

4. 実験計画の用語

定義

処理群・対照群
処理を施す群と、比較のために処理を施さない群
反復
同じ条件で複数回測定すること。誤差の大きさを評価できるようになる
無作為化
処理の割り付けをランダムに行うこと。偏りを防ぐ
局所管理（ブロック化）
条件の似た実験単位をまとめたブロックの中で比較すること。ブロック間の差を誤差から取り除ける

覚え方：フィッシャーの3原則

反復・無作為化・局所管理。

注意

  • 2群の𝑡検定を何度も繰り返して3群以上を比べると、どれかで誤って有意になる確率（第1種の過誤）が𝛼より大きくなる。そのため分散分析でまとめて検定する。
  • 群が2つの場合、一元配置分散分析は等分散を仮定した2標本𝑡検定と一致する（𝐹=𝑇2）。

回帰係数の検定、母平均の差の検定も参照。
