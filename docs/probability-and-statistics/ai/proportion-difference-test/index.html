母比率の差の検定

Keywords: #統計検定, #仮説検定

目次

  1. 1. 検定統計量

2つの母集団の母比率を𝑝1、𝑝2とする。 それぞれから大きさ𝑚、𝑛の独立な標本をとり、性質をもつものが𝑋個、𝑌個だったとき、

𝐻 0 : 𝑝 1 = 𝑝 2

を検定する。

1. 検定統計量

標本比率を𝑝̂1=𝑋/𝑚、𝑝̂2=𝑌/𝑛とする。 𝐻0のもとでは𝑝1=𝑝2=𝑝なので、共通の𝑝を2つの標本をまとめて推定する。

定義：プールした比率

𝑝 ̂ = 𝑋 + 𝑌 𝑚 + 𝑛

定理

𝐻0:𝑝1=𝑝2のもとで、𝑚,𝑛が十分大きければ近似的に

𝑍 = 𝑝 ̂ 1 − 𝑝 ̂ 2 𝑝 ̂ ( 1 − 𝑝 ̂ ) ( 1 𝑚 + 1 𝑛 ) ∼ 𝑁 ( 0 , 1 )

有意水準𝛼の棄却域は次のとおり。

両側検定
|𝑍|>𝑧(𝛼2)⟹𝑝1≠𝑝2
右側検定
𝑍>𝑧(𝛼)⟹𝑝1>𝑝2
左側検定
𝑍<−𝑧(𝛼)⟹𝑝1<𝑝2

覚え方

  • 独立な2つの比率の差の分散は𝑝1(1−𝑝1)𝑚+𝑝2(1−𝑝2)𝑛。 𝐻0のもとで𝑝1=𝑝2=𝑝とおくと𝑝(1−𝑝)(1𝑚+1𝑛)になり、この𝑝を𝑝̂で推定する。
  • 「検定は𝐻0のもとで計算する」ので、プールした𝑝̂を使う。 区間推定では𝐻0がないので、𝑝̂1、𝑝̂2を別々に使う。この違いはよく問われる。

例題

A地区では 200 人中 120 人、B地区では 300 人中 150 人がある政策に賛成した。 賛成率に差があるか、有意水準 5 % で両側検定せよ。

𝑝̂1=0.6、𝑝̂2=0.5、𝑝̂=120+150200+300=0.54なので

𝑧 = 0.6 − 0.5 0.54 × 0.46 × ( 1 200 + 1 300 ) ≈ 0.1 0.0455 ≈ 2.20

2.20>1.96なので𝐻0を棄却し、賛成率に差があると判断する（𝑝≈0.028）。

注意

2×2のクロス表で比率の差を調べる場合、この検定は独立性の検定と同じ結論になる（ 𝑍 2 が独立性の検定の 𝜒 2 統計量に一致する）。
