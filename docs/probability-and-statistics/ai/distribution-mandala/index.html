統計検定2級に登場する分布は、ばらばらに覚えるより「どの分布から、どう作られるか」の関係で覚えたほうが整理しやすい。 その関係を1枚にまとめたものを、ここでは分布の曼陀羅と呼ぶ。

各分布の定義は確率分布のまとめと標本分布のまとめを参照のこと。

1. 曼陀羅

記号 意味
実線の矢印 和・変換・特別な場合（ちょうどその分布になる）
破線の矢印 極限・近似（パラメータを動かすと近づく）
青 離散型の分布
緑 連続型の分布
黄 正規分布の仲間
赤 正規分布から作る標本分布

2. 矢印の意味

2.1. ベルヌーイ分布から広がる離散分布

関係 内容
ベルヌーイ → 二項 独立な𝐵(1,𝑝)を𝑛個足すと𝐵𝑖𝑛(𝑛,𝑝)
ベルヌーイ → 幾何 𝐵(1,𝑝)を繰り返し、初めて成功するまでの失敗回数が𝐺(𝑝)
幾何 → 負の二項 独立な𝐺(𝑝)を𝑟個足すと𝑁𝐵(𝑟,𝑝)（𝑟回目の成功まで）
超幾何 → 二項 母集団𝑁→∞（𝑀𝑁=𝑝一定）で、非復元抽出が復元抽出と変わらなくなる
二項 → ポアソン 𝑛→∞、𝑝→0（𝑛𝑝=𝜆一定）の極限。稀な事象の回数
二項 → 正規 𝑛が大きいと𝑁(𝑛𝑝,𝑛𝑝(1−𝑝))で近似できる（中心極限定理）
ポアソン → 正規 𝜆が大きいと𝑁(𝜆,𝜆)で近似できる

2.2. 回数と時間の対応

関係 内容
ポアソン ⇄ 指数 単位時間に平均𝜆回起こるとき、時刻𝑡までの回数が𝑃𝑜(𝜆𝑡)、発生の間隔が𝐸𝑥(𝜆)。同じ現象を回数と時間の両側から見たもの（確率分布のまとめの「ポアソン過程」の節を参照）
幾何 → 指数 「何回目で起こるか」を連続時間にした極限。どちらも無記憶性をもつ
負の二項 → Γ 「𝑟回目まで」を連続時間にした極限
指数 → Γ 独立な𝐸𝑥(𝜆)を𝛼個足すとΓ(𝛼,𝜆)。𝐸𝑥(𝜆)=Γ(1,𝜆)
一様 → 指数 𝑈∼𝑈(0,1)なら−1𝜆log𝑈∼𝐸𝑥(𝜆)（逆関数法による乱数生成）

2.3. 正規分布と標本分布

関係 内容
2変量正規 → 正規 2変量正規分布の周辺分布・条件付き分布は正規分布
正規 → 標準正規 𝑋∼𝑁(𝜇,𝜎2)なら𝑋−𝜇𝜎∼𝑁(0,1)
標準正規 → 𝜒2 独立な𝑍𝑖∼𝑁(0,1)について𝑍12+⋯+𝑍𝑛2∼𝜒2(𝑛)
Γ → 𝜒2 𝜒2(𝑛)=Γ(𝑛2,12)。とくに𝜒2(2)=𝐸𝑥(12)
標準正規・𝜒2 → 𝑡 𝑍/𝑋/𝑛∼𝑡(𝑛)（𝑍∼𝑁(0,1)、𝑋∼𝜒2(𝑛)独立）
𝑡 → 標準正規 𝑛→∞で𝑡(𝑛)→𝑁(0,1)
𝜒2 → 𝐹 𝑋/𝑚𝑌/𝑛∼𝐹(𝑚,𝑛)（𝑋∼𝜒2(𝑚)、𝑌∼𝜒2(𝑛)独立）
𝑡 → 𝐹 𝑇∼𝑡(𝑛)なら𝑇2∼𝐹(1,𝑛)

3. 覚え方

覚え方：3つの系統

  1. 数える系（離散）：ベルヌーイ → 二項 → ポアソン。「何回起こったか」
  2. 待つ系：幾何 → 負の二項（離散）、指数 → Γ（連続）。「いつ起こるか」
  3. 正規系：正規 → 𝜒2 → 𝑡、𝐹。「標本から母集団を推測する」

覚え方：離散と連続のペア

意味 離散 連続
1回目までの待ち 幾何分布 指数分布
𝑟回目までの待ち 負の二項分布 Γ分布
無記憶性をもつ 幾何分布 指数分布

離散の「回数」を連続の「時間」に置き換えると、ちょうど対応する分布になる。

覚え方：「足すと同じ分布」になるもの（再生性）

二項（ 𝑝 が同じ）、ポアソン、負の二項（ 𝑝 が同じ）、正規、 Γ （ 𝜆 が同じ）、 𝜒 2 。 曼陀羅の「 𝑛 個の和」「 𝛼 個の和」の矢印は、すべて再生性の現れである。

覚え方：最後は正規分布に集まる

二項・ポアソン・ 𝑡 の破線の矢印は、どれも正規分布に向かう。 「たくさん足す」「自由度を大きくする」と正規分布になるのは、中心極限定理のおかげ。 迷ったら「 𝑛 が大きければ正規近似」と考えてよい。
