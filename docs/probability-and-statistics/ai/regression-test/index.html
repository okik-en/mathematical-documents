回帰係数の検定

Keywords: #統計検定, #仮説検定, #回帰分析

目次

  1. 1. 単回帰の傾きの検定
  2. 2. 自由度が大きいときの正規近似
  3. 3. 重回帰の回帰係数の検定
  4. 4. 回帰式全体の𝐹検定

回帰分析で得られた係数が「本当に0でないか」（説明変数が目的変数の説明に役立っているか）を調べる。 推定量の分布や信頼区間は回帰係数の推定にまとめてある。

1. 単回帰の傾きの検定

定義：単回帰モデル

𝑌 𝑖 = 𝛽 0 + 𝛽 1 𝑥 𝑖 + 𝜀 𝑖 , 𝜀 𝑖 ∼ 𝑁 ( 0 , 𝜎 2 ) （独立） ( 𝑖 = 1 , … , 𝑛 )

最小二乗法による推定値は

𝛽 ̂ 1 = 𝑆 𝑥 𝑦 𝑆 𝑥 𝑥 , 𝛽 ̂ 0 = 𝑦 − 𝛽 ̂ 1 𝑥

ここで𝑆𝑥𝑥=∑(𝑥𝑖−𝑥)2、𝑆𝑥𝑦=∑(𝑥𝑖−𝑥)(𝑦𝑖−𝑦)である。

残差𝑒𝑖=𝑦𝑖−(𝛽̂0+𝛽̂1𝑥𝑖)を使って、誤差分散𝜎2を

𝑠 2 = ∑ 𝑒 𝑖 2 𝑛 − 2

で推定する。

定理

𝐻0:𝛽1=0のもとで

𝑇 = 𝛽 ̂ 1 se ( 𝛽 ̂ 1 ) ∼ 𝑡 ( 𝑛 − 2 ) , se ( 𝛽 ̂ 1 ) = 𝑠 𝑆 𝑥 𝑥

有意水準𝛼の両側検定では|𝑇|>𝑡𝑛−2(𝛼2)なら𝐻0を棄却し、「𝑥は𝑦の説明に有意に役立っている」と判断する。

覚え方

  • 形は「推定値 ÷ 標準誤差」。母平均の𝑡検定と同じ考え方。
  • 自由度は𝑛−2。𝛽0と𝛽1の2つを推定したぶん減る。
  • 𝑆𝑥𝑥が大きい（𝑥が広く散らばっている）ほど標準誤差は小さく、傾きを精度よく推定できる。

例題

𝑛 = 12 組のデータで単回帰を行ったところ、傾きの推定値が 0.8 、その標準誤差が 0.3 だった。 𝐻 0 : 𝛽 1 = 0 を有意水準 5 % で両側検定せよ。
𝑡 = 0.8 0.3 ≈ 2.67

自由度12−2=10で𝑡10(0.025)≈2.228。2.67>2.228なので𝐻0を棄却する（𝑝≈0.024）。

2. 自由度が大きいときの正規近似

残差の自由度𝑛−2（重回帰なら𝑛−𝑝−1）が十分大きいとき、𝑡分布は標準正規分布で近似できる。

定理

自由度が大きければ、𝐻0:𝛽1=0のもとで近似的に

𝑍 = 𝛽 ̂ 1 se ( 𝛽 ̂ 1 ) ∼ 𝑁 ( 0 , 1 )

であり、両側検定の棄却域は|𝑍|>𝑧(𝛼2)（5%なら1.96）としてよい。

例題

𝑛 = 102 組のデータで単回帰を行ったところ、傾きの推定値が 0.5 、標準誤差が 0.2 だった。 𝐻 0 : 𝛽 1 = 0 を有意水準 5 % で両側検定せよ。

自由度は100と大きいので正規近似を用いる。 𝑧=0.5/0.2=2.5>1.96なので𝐻0を棄却する（𝑝≈0.012）。 𝑡(100)を正確に使っても𝑡100(0.025)≈1.984で、結論は変わらない。

覚え方

  • 自由度が30程度を超えたら𝑡≈𝑧。𝑡分布表がなくても1.96（両側5%）、2.576（両側1%）で判断できる。
  • ソフトウェアの出力で「|t value|>2なら大体5%有意」と読めるのは、この正規近似のおかげ。
  • 自由度が小さいときに正規近似を使うと、棄却域が広くなりすぎて第1種の過誤が増える。

3. 重回帰の回帰係数の検定

説明変数が𝑝個の重回帰モデル

𝑌 𝑖 = 𝛽 0 + 𝛽 1 𝑥 𝑖 1 + ⋯ + 𝛽 𝑝 𝑥 𝑖 𝑝 + 𝜀 𝑖

では、各係数について同じ形の𝑡検定を行う。

定理

𝐻0:𝛽𝑗=0のもとで

𝑇 = 𝛽 ̂ 𝑗 se ( 𝛽 ̂ 𝑗 ) ∼ 𝑡 ( 𝑛 − 𝑝 − 1 )

覚え方

  • 自由度は「𝑛 −（推定した係数の数）」=𝑛−(𝑝+1)。単回帰は𝑝=1の場合。
  • 重回帰の係数𝛽̂𝑗は偏回帰係数。「他の説明変数を固定したときの効果」なので、単回帰の傾きとは値も符号も変わりうる。
  • 説明変数同士の相関が強い（多重共線性）と標準誤差が大きくなり、個々の係数が有意になりにくい。

4. 回帰式全体の𝐹検定

「説明変数がどれも役に立っていない」かどうかを、まとめて検定する。

定理

𝐻0:𝛽1=𝛽2=⋯=𝛽𝑝=0のもとで

𝐹 = 𝑆 𝑅 / 𝑝 𝑆 𝑒 / ( 𝑛 − 𝑝 − 1 ) ∼ 𝐹 ( 𝑝 , 𝑛 − 𝑝 − 1 )

ここで𝑆𝑅=∑(𝑦̂𝑖−𝑦)2は回帰平方和、𝑆𝑒=∑𝑒𝑖2は残差平方和。

𝐹>𝐹𝑛−𝑝−1𝑝(𝛼)なら𝐻0を棄却する（右側検定）。

決定係数𝑅2=𝑆𝑅/(𝑆𝑅+𝑆𝑒)を使うと

𝐹 = 𝑅 2 / 𝑝 ( 1 − 𝑅 2 ) / ( 𝑛 − 𝑝 − 1 )

とも書ける。

覚え方

  • 「回帰で説明できた変動」と「説明できなかった変動」を、それぞれ自由度で割ってから比べる。分散分析と同じ考え方。
  • 単回帰（𝑝=1）では、傾きの𝑡統計量の2乗が𝐹統計量に一致する（𝑡(𝑛−2)2=𝐹(1,𝑛−2)）。

5. ソフトウェア出力の読み方

統計ソフトウェアの回帰分析の出力には、たいてい次の列が並ぶ。

Estimate Std. Error t value Pr(>|t|)
(Intercept) 𝛽̂0 se(𝛽̂0) 𝛽̂0/se(𝛽̂0) 𝑝値
x1 𝛽̂1 se(𝛽̂1) 𝛽̂1/se(𝛽̂1) 𝑝値

覚え方

  • t value = Estimate ÷ Std. Error。どれか1つが空欄になっていて、それを計算させる問題が多い。
  • Pr(>|t|)は両側検定の𝑝値。0.05未満なら有意水準5%で有意。
  • 出力の下のほうにあるF-statisticとその𝑝値が、回帰式全体の𝐹検定。
