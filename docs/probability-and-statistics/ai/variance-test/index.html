母分散の検定

Keywords: #統計検定, #仮説検定

目次

  1. 1. 検定統計量

正規母集団𝑁(𝜇,𝜎2)（𝜇も未知）から大きさ𝑛の無作為標本をとり、母分散𝜎2について

𝐻 0 : 𝜎 2 = 𝜎 0 2

を検定する。

1. 検定統計量

定理

𝐻0:𝜎2=𝜎02のもとで

𝜒 2 = ( 𝑛 − 1 ) 𝑈 2 𝜎 0 2 = ∑ 𝑖 = 1 𝑛 ( 𝑋 𝑖 − 𝑋 ) 2 𝜎 0 2 ∼ 𝜒 2 ( 𝑛 − 1 )

有意水準𝛼の棄却域は次のとおり。

両側検定
𝜒2<𝜒𝑛−12(1−𝛼2)または𝜒2>𝜒𝑛−12(𝛼2)⟹𝜎2≠𝜎02
右側検定
𝜒2>𝜒𝑛−12(𝛼)⟹𝜎2>𝜎02
左側検定
𝜒2<𝜒𝑛−12(1−𝛼)⟹𝜎2<𝜎02

覚え方

  • 分子は偏差平方和∑(𝑋𝑖−𝑋)2=(𝑛−1)𝑈2。これを仮説の分散𝜎02で割る。
  • 𝐻0が正しければ𝑈2≈𝜎02なので、𝜒2はだいたい自由度𝑛−1（𝜒2分布の平均）くらいになる。 それより極端に大きい・小さいと𝐻0が疑わしい。
  • 𝜒2分布は左右非対称なので、両側検定の下側の点は𝜒𝑛−12(1−𝛼2)を分布表から別に読む（𝑡分布のようにマイナスをつけるだけでは求まらない）。

例題

正規母集団から 𝑛 = 10 の標本をとったところ、不偏分散が 𝑢 2 = 2.5 だった。 𝐻 0 : 𝜎 2 = 1.5 、 𝐻 1 : 𝜎 2 > 1.5 を有意水準 5 % で検定せよ。
𝜒 2 = 9 × 2.5 1.5 = 15.0

自由度9の上側5%点は𝜒92(0.05)≈16.92で、15.0<16.92なので𝐻0を棄却しない（𝑝≈0.091）。

なお両側検定（有意水準5%）なら、棄却域は𝜒2<𝜒92(0.975)≈2.70または𝜒2>𝜒92(0.025)≈19.02である。

注意

  • 母平均𝜇が既知の場合は、𝑋の代わりに𝜇を使って∑(𝑋𝑖−𝜇)2/𝜎02∼𝜒2(𝑛)となり、自由度は𝑛になる。
  • この検定は母集団が正規分布であることに強く依存する。正規分布から外れていると結果が大きく狂うので注意。

母分散の比の検定、標本分布のまとめも参照。
