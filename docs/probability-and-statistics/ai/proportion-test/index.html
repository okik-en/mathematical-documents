母比率の検定

Keywords: #統計検定, #仮説検定

目次

  1. 1. 検定統計量

ある性質をもつものの割合（母比率）を𝑝とする。 大きさ𝑛の標本のうち、その性質をもつものが𝑋個だったとき、

𝐻 0 : 𝑝 = 𝑝 0

を検定する。

1. 検定統計量

𝑋∼𝐵𝑖𝑛(𝑛,𝑝)で、𝔼[𝑋]=𝑛𝑝、Var[𝑋]=𝑛𝑝(1−𝑝)である。 標本比率𝑝̂=𝑋/𝑛は平均𝑝、分散𝑝(1−𝑝)/𝑛をもつ。

𝑛が大きければ二項分布は正規分布で近似できるので、次が成り立つ。

定理

𝐻0:𝑝=𝑝0のもとで、𝑛が十分大きければ近似的に

𝑍 = 𝑝 ̂ − 𝑝 0 𝑝 0 ( 1 − 𝑝 0 ) / 𝑛 = 𝑋 − 𝑛 𝑝 0 𝑛 𝑝 0 ( 1 − 𝑝 0 ) ∼ 𝑁 ( 0 , 1 )

有意水準𝛼の棄却域は次のとおり。

両側検定
|𝑍|>𝑧(𝛼2)⟹𝑝≠𝑝0
右側検定
𝑍>𝑧(𝛼)⟹𝑝>𝑝0
左側検定
𝑍<−𝑧(𝛼)⟹𝑝<𝑝0

覚え方

  • 「標本比率 − 仮説の比率」を「標準誤差」で割る、という母平均の𝑍検定と同じ形。
  • 分母の標準誤差には仮説の値𝑝0を使う。 区間推定では𝑝がわからないので𝑝̂を使うが、検定では𝐻0のもとで𝑝=𝑝0とわかっているので𝑝0を使う。
  • 正規近似の目安：𝑛𝑝0≥5かつ𝑛(1−𝑝0)≥5。

例題

コインを 400 回投げたところ、表が 220 回出た。 このコインは公正（ 𝑝 = 0.5 ）といえるか、有意水準 5 % で両側検定せよ。

𝑝̂=220/400=0.55なので

𝑧 = 0.55 − 0.5 0.5 × 0.5 / 400 = 0.05 0.025 = 2.0

|𝑧|=2.0>1.96なので𝐻0を棄却し、公正とはいえないと判断する（𝑝≈0.046）。

注意：連続修正

離散的な𝑋を連続的な正規分布で近似するため、𝑋を±0.5だけ補正する連続修正を行うことがある。 例えば右側検定なら

𝑍 = ( 𝑋 − 0.5 ) − 𝑛 𝑝 0 𝑛 𝑝 0 ( 1 − 𝑝 0 )

とする。𝑛が大きければ影響は小さい。

母比率の差の検定、近似も参照。
