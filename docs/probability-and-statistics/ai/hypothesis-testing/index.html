個々の検定の前に、すべての検定で共通する考え方をまとめる。

1. 仮説検定の考え方

仮説検定は背理法の確率版である。

  1. 否定したい仮説（帰無仮説𝐻0）を立てる
  2. 𝐻0が正しいと仮定して、データから計算した値（検定統計量）の分布を求める
  3. 実際の検定統計量が「𝐻0のもとではめったに起こらない値」なら、𝐻0を棄却し、対立仮説𝐻1を採択する

定義：用語

帰無仮説𝐻0
「差がない」「効果がない」など、等号を含む仮説。例：𝜇=𝜇0
対立仮説𝐻1
主張したい仮説。例：𝜇≠𝜇0、𝜇>𝜇0
検定統計量
𝐻0のもとで分布がわかる統計量。例：𝑍=𝑋−𝜇0𝜎/𝑛
有意水準𝛼
「めったに起こらない」の基準となる確率。通常0.05や0.01
棄却域
𝐻0を棄却する検定統計量の範囲。𝐻0のもとでその範囲に入る確率が𝛼になるように決める

注意：「棄却できない」は「正しい」ではない

𝐻 0 が棄却されなかったとき、それは「 𝐻 0 を否定するだけの証拠がなかった」にすぎず、𝐻0が正しいと示されたわけではない。 そのため「 𝐻 0 を採択する」ではなく「 𝐻 0 を棄却しない」と表現する。

2. 両側検定と片側検定

対立仮説の形によって、棄却域を置く場所が変わる。 検定統計量𝑍∼𝑁(0,1)（𝐻0のもと）の場合、有意水準𝛼で

両側検定
𝐻1:𝜇≠𝜇0。棄却域は|𝑍|>𝑧(𝛼2)
右側検定
𝐻1:𝜇>𝜇0。棄却域は𝑍>𝑧(𝛼)
左側検定
𝐻1:𝜇<𝜇0。棄却域は𝑍<−𝑧(𝛼)

ここで𝑧(𝛼)は標準正規分布の上側100𝛼%点である。

𝛼 両側（𝑧(𝛼2)） 片側（𝑧(𝛼)）
0.10 1.645 1.282
0.05 1.960 1.645
0.01 2.576 2.326

覚え方

  • 両側検定は𝛼を左右に半分ずつ配る。だから𝑧(𝛼2)を使う。
  • 「1.96は両側5%、1.645は片側5%」の2つは必ず覚える。
  • 片側検定を使うのは、「𝜇が小さくなることはありえない」など、データを見る前から方向が決まっているときだけである。データを見てから方向を決めてはいけない。

3. 𝑝値

定義

𝐻 0 が正しいとしたとき、実際に得られた検定統計量と同じか、それより極端な値が出る確率を𝑝値という。

𝑝値を使うと、検定のルールは次のように言い換えられる。

𝑝 < 𝛼 ⟺ 𝐻 0 を棄却する

例えば𝑍検定で検定統計量が𝑧0=2.0だったとき、

  • 右側検定なら𝑝=Pr{𝑍≥2.0}≈0.023
  • 両側検定なら𝑝=Pr{|𝑍|≥2.0}=2Pr{𝑍≥2.0}≈0.046

であり、どちらも𝑝<0.05なので有意水準5%で𝐻0を棄却する。

覚え方

  • 𝑝値は「𝐻0のもとでの珍しさ」。小さいほど𝐻0を疑う根拠が強くなる。
  • 両側検定の𝑝値は片側の2倍。
  • 𝑝値は「𝐻0が正しい確率」ではない。ここはよく問われる。

4. 第1種の過誤と第2種の過誤

検定は確率的な判断なので、2種類の誤りが起こりうる。

𝐻0が真 𝐻1が真
𝐻0を棄却 第1種の過誤（確率𝛼） 正しい（確率1−𝛽 = 検出力）
𝐻0を棄却しない 正しい（確率1−𝛼） 第2種の過誤（確率𝛽）

定義

第1種の過誤
𝐻0が正しいのに棄却してしまう誤り。その確率は有意水準𝛼に等しい。あわてものの誤り
第2種の過誤
𝐻1が正しいのに𝐻0を棄却しない誤り。その確率を𝛽とする。ぼんやりものの誤り
検出力
𝐻1が正しいときに、正しく𝐻0を棄却する確率1−𝛽

覚え方

  • 第1種は「1人で騒ぐ（ないものをあると言う）」、第2種は「見逃す」。
  • 「あわてもの（第1種）」「ぼんやりもの（第2種）」という覚え方が定番。
  • 標本サイズ𝑛を固定したまま𝛼を小さくすると、𝛽は大きくなる（トレードオフ）。両方を小さくするには𝑛を大きくするしかない。

5. 検出力の計算

例題

𝑁 ( 𝜇 , 5 2 ) から 𝑛 = 25 の標本をとり、 𝐻 0 : 𝜇 = 50 、 𝐻 1 : 𝜇 > 50 を有意水準 5 % で検定する。 真の平均が 𝜇 = 52 のときの検出力を求めよ。

𝑋∼𝑁(𝜇,52/25)=𝑁(𝜇,12)である。

棄却域は𝑋−501>1.645、すなわち𝑋>51.645である。

真の平均が52のとき、𝑋∼𝑁(52,1)なので、検出力は

Pr { 𝑋 > 51.645 } = Pr { 𝑋 − 52 1 > 51.645 − 52 1 } = Pr { 𝑍 > − 0.355 } ≈ 0.64

となる。第2種の過誤の確率は𝛽≈0.36である。

覚え方：検出力が上がる条件

  • 標本サイズ𝑛が大きい
  • 真の値と𝐻0の値の差が大きい
  • 母標準偏差𝜎が小さい
  • 有意水準𝛼が大きい（ただし第1種の過誤は増える）

6. 検定の手順

  1. 帰無仮説𝐻0と対立仮説𝐻1を立てる（両側か片側かもここで決める）
  2. 有意水準𝛼を決める
  3. 状況に合った検定統計量を選び、𝐻0のもとでの分布を確認する
  4. 棄却域を求める（または𝑝値を計算する）
  5. 検定統計量の実現値が棄却域に入るか（𝑝<𝛼か）で判断する
