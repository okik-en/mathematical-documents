信頼区間

目次

  2. 2. 信頼区間の導出

確率変数𝑋∼𝑁(𝜇,𝜎2)を用意する（𝜎>0とする）。 𝑋の100(1−𝛼)%両側信頼区間を求めよう。

1. 標準化変数

いま、𝑍=𝑎𝑋+𝑏で、かつ𝑍∼𝑁(0,1)と仮定する（正規分布の再生性よりそのような𝑍が存在する）。

このとき、期待値および分散の性質より

0 = 𝔼 [ 𝑍 ] = 𝔼 [ 𝑎 𝑋 + 𝑏 ] = 𝑎 𝔼 [ 𝑋 ] + 𝑏 = 𝑎 𝜇 + 𝑏 1 = Var [ 𝑍 ] = Var [ 𝑎 𝑋 + 𝑏 ] = 𝑎 2 Var [ 𝑋 ] = 𝑎 2 𝜎 2

がいえる。

後者より：

𝑎 = 1 𝜎

また前者より：

𝑏 = − 𝑎 𝜇 = − 𝜇 𝜎

ゆえにそのような𝑍∼𝑁(0,1)は

𝑍 = 𝑋 − 𝜇 𝜎

と表せて、これを𝑋の標準化変数と呼ぶ。

2. 信頼区間の導出

いま、𝑍∼𝑁(0,1)の上側100𝛽%点を𝑧(𝛽)とする。 すなわち：

Pr { 𝑍 ≥ 𝑧 ( 𝛽 ) } = 𝛽

このとき、|𝑍|≥𝑧(𝛽)となる確率は、正規分布の対称性より

Pr { | 𝑍 | ≥ 𝑧 ( 𝛽 ) } = Pr { 𝑍 ≥ 𝑧 ( 𝛽 ) } + Pr { 𝑍 ≤ − 𝑧 ( 𝛽 ) } = 2 Pr { 𝑍 ≥ 𝑧 ( 𝛽 ) } = 2 𝛽

であるから、2𝛽=𝛼とすれば

Pr { | 𝑍 | ≥ 𝑧 ( 𝛼 2 ) } = 100 𝛼 %

すなわち

Pr { | 𝑍 | ≤ 𝑧 ( 𝛼 2 ) } = 100 ( 1 − 𝛼 ) %

が成り立つ。

先程𝑍=𝑋−𝜇𝜎であったから、これは

| 𝑋 − 𝜇 | 𝜎 ≤ 𝑧 ( 𝛼 2 ) ⟺ | 𝑋 − 𝜇 | ≤ 𝑧 ( 𝛼 2 ) 𝜎 ⟺ 𝑋 − 𝜇 ≥ − 𝑧 ( 𝛼 2 ) 𝜎 ∨ 𝑋 − 𝜇 ≤ 𝑧 ( 𝛼 2 ) 𝜎 ⟺ 𝑋 ∈ [ 𝜇 − 𝑧 ( 𝛼 2 ) 𝜎 , 𝜇 + 𝑧 ( 𝛼 2 ) 𝜎 ]

であり、ゆえに

Pr { 𝑋 ∈ [ 𝜇 − 𝑧 ( 𝛼 2 ) 𝜎 , 𝜇 + 𝑧 ( 𝛼 2 ) 𝜎 ] } = 100 ( 1 − 𝛼 ) %

がいえる。

すなわち、𝑋の100(1−𝛼)%両側信頼区間は

[ 𝜇 − 𝑧 ( 𝛼 2 ) 𝜎 , 𝜇 + 𝑧 ( 𝛼 2 ) 𝜎 ]

と求まる。
