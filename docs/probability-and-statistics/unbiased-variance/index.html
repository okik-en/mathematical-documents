1. 標本分散の非不偏性

いま母平均𝜇、母分散𝜎2の分布から抽出した標本の分散𝑆2は

𝑆 2 = 1 𝑛 ∑ 𝑖 = 1 𝑛 ( 𝑥 𝑖 − 𝑥 ) 2 = 1 𝑛 ∑ 𝑖 = 1 𝑛 [ ( 𝑥 𝑖 − 𝜇 ) − ( 𝑥 − 𝜇 ) ] 2 = 1 𝑛 ∑ 𝑖 = 1 𝑛 ( 𝑥 𝑖 − 𝜇 ) 2 − 2 𝑛 ( 𝑥 − 𝜇 ) ∑ 𝑖 = 1 𝑛 ( 𝑥 𝑖 − 𝜇 ) + ( 𝑥 − 𝜇 ) 2 = 1 𝑛 ∑ 𝑖 = 1 𝑛 ( 𝑥 𝑖 − 𝜇 ) 2 − ( 𝑥 − 𝜇 ) 2 ⎵

であるから、期待値の線形性より

𝔼 [ 𝑆 2 ] = 1 𝑛 ∑ 𝑖 = 1 𝑛 𝔼 [ ( 𝑥 𝑖 − 𝜇 ) 2 ] − 𝔼 [ ( 𝑥 − 𝜇 ) 2 ] ⎵ = 1 𝑛 Var [ 𝑥 𝑖 ] − Var [ 𝑥 ] = 1 𝑛 𝑛 𝜎 2 − 𝜎 2 𝑛 = 𝑛 − 1 𝑛 𝜎 2

となる。 すなわち、(𝑥−𝜇)2のために標本分散𝑆2は母分散𝜎2の不偏推定量ではない。

2. 不偏分散

上の式と期待値の線形性より

𝔼 [ 𝑛 𝑛 − 1 𝑆 2 ] = 𝜎 2

がいえて、この

𝑈 2 = 𝑛 𝑛 − 1 𝑆 2 = 1 𝑛 − 1 ∑ 𝑖 = 1 𝑛 ( 𝑥 𝑖 − 𝑥 ) 2

を不偏分散という。

3. 不偏分散の一致性

不偏分散𝑈2は母分散𝜎2の一致推定量である。

まず、大数の法則より

𝑥 = 1 𝑛 ∑ 𝑖 = 1 𝑛 𝑥 𝑖 ⟶ 𝑃 𝜇 , 𝑥 2 = 1 𝑛 ∑ 𝑖 = 1 𝑛 𝑥 𝑖 2 ⟶ 𝑃 𝜇 2 + 𝜎 2

であるから

𝑆 2 = 𝑥 2 − ( 𝑥 ) 2 ⟶ 𝑃 ( 𝜇 2 + 𝜎 2 ) − 𝜇 2 = 𝜎 2

とわかる。

よって

𝑈 2 = 𝑛 𝑛 − 1 𝑆 2 ⟶ 𝑃 𝜎 2

であり、ゆえに不偏分散𝑈2は母分散𝜎2の一致推定量である。

一方で、不偏分散は母分散の有効推定量ではないことが知られている。
