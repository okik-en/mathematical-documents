2. Size of Registers

Byte .b
1 Byte = 8 bits
Word .w
2 Bytes = 16 bits
Long Word .l
4 Bytes = 32 bits (register size)

3. Data Representation

Little Endian

0x12345678
---
00: 1 2

4. Addressing Modes

Immediate data
#0x1234 → 0x1234
Absolute address
0x1000 → (mem+) 0x1000
Data/Address register direct
%a0 → (reg+) a0
Address register indirect
(%a0) → (mem+) reg[a0]
Postincrement address register indirect
(%a0)+ → (mem+) reg[a0]++
Predecrement address register indirect
-(%a0) → (mem+) --reg[a0]
Indexed address register indirect
d8(%a0, %d1.l) → (mem+) reg[a0] + reg[d1] + FFFFFFFF
