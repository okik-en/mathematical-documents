4. Branch

Reference about branch, Reference about CCR

cmp.l  <x> <y>  // CCR := y - x

bhi    <label>  // on CCR > 0 (x < y)
bcc    <label>  // on CCR >= 0 (x <= y)
beq    <label>  // on CCR == 0 (x == y)
bne    <label>  // on CCR != 0 (x != y)

5. Sub routine

jsr    <addr>
rts             // return
