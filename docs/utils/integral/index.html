1. 双曲線関数

双曲線関数について考える。

{ sinh 𝜃 = 𝑒 𝜃 − 𝑒 − 𝜃 2 cosh 𝜃 = 𝑒 𝜃 + 𝑒 − 𝜃 2

双曲線関数について、定義より

cosh 2 𝜃 − sinh 2 𝜃 = ( 𝑒 𝜃 + 𝑒 − 𝜃 2 ) 2 − ( 𝑒 𝜃 − 𝑒 − 𝜃 2 ) 2 = 1

がいえる。

あるいは微分すると

{ ( sinh 𝜃 ) ′ = ( 𝑒 𝜃 − 𝑒 − 𝜃 2 ) ′ = 𝑒 𝜃 + 𝑒 − 𝜃 2 = cosh 𝜃 ( cosh 𝜃 ) ′ = ( 𝑒 𝜃 + 𝑒 − 𝜃 2 ) ′ = 𝑒 𝜃 − 𝑒 − 𝜃 2 = sinh 𝜃

を得る。

以上によれば、次の積分

∫ 𝑑 𝑥 𝑥 2 + 𝑎 2 ( 𝑎 > 0 )

は𝑥=𝑎sinh𝜃(⇒𝑑𝑥=𝑎cosh𝜃𝑑𝜃)とおくことにより𝑥2+𝑎2=𝑎cosh𝜃がいえて

∫ 𝑑 𝑥 𝑥 2 + 𝑎 2 = ∫ 𝑎 cosh 𝜃 𝑑 𝜃 𝑎 cosh 𝜃 = ∫ 𝑑 𝜃 = sinh − 1 ( 𝑥 𝑎 ) + 𝐶 ′

を得る。

ここで逆関数は解の公式などにより

{ sinh − 1 𝑢 = log ( 𝑢 + 𝑢 2 + 1 ) cosh − 1 𝑢 = log ( 𝑢 + 𝑢 2 − 1 )

と得られることを踏まえて

∫ 𝑑 𝑥 𝑥 2 + 𝑎 2 = log 𝑎 ( 𝑥 + 𝑥 2 + 𝑎 2 ) + 𝐶 ′ = log ( 𝑥 + 𝑥 2 + 𝑎 2 ) + 𝐶
[1]

とわかる。

2. Euler置換

式 [1]の積分を、𝑡=𝑎−1exp(sinh−1(𝑥𝑎))=𝑥+𝑥2+𝑎2とおくことにより解こう。

これは逆関数を考えると

𝑥 = 1 2 ( 𝑡 − 𝑎 2 𝑡 )

であり、この置換をEuler置換という。

Euler置換に依れば

𝑑 𝑥 = 1 2 ( 1 + 𝑎 2 𝑡 2 ) 𝑑 𝑡 , 𝑥 2 + 𝑎 2 = 1 2 ( 𝑡 + 𝑎 2 𝑡 )

となるため

∫ 𝑑 𝑥 𝑥 2 + 𝑎 2 = ∫ 1 2 ( 1 + 𝑎 2 𝑡 2 ) 1 2 ( 𝑡 + 𝑎 2 𝑡 ) 𝑑 𝑡 = ∫ 𝑑 𝑡 𝑡 = log ( 𝑥 + 𝑥 2 + 𝑎 2 ) + 𝐶

と得られる。

3. Weierstrass置換

三角関数の積分

𝐼 ( 𝜃 ) = ∫ 𝑓 ( sin 𝜃 , cos 𝜃 , tan 𝜃 ) d 𝜃

を、Weierstrass置換

𝑡 = tan 𝜃 2

により解くことを考える。

置換の両辺を微分することにより

d 𝑡 = 1 2 d 𝜃 cos 2 𝜃 2 ⟹ 2 1 + 𝑡 2 d 𝑡 = d 𝜃

を得ることができる。また

{ sin 𝜃 = 2 sin 𝜃 2 cos 𝜃 2 = 2 tan 𝜃 2 cos 2 𝜃 2 = 2 tan 𝜃 1 − tan 2 𝜃 2 = 2 𝑡 1 − 𝑡 2 cos 𝜃 = 2 cos 2 𝜃 2 − 1 = 2 1 − tan 2 𝜃 2 − 1 = 1 + tan 2 𝜃 2 1 − tan 2 𝜃 2 = 1 + 𝑡 2 1 − 𝑡 2 tan 𝜃 = sin 𝜃 cos 𝜃 = 2 𝑡 1 + 𝑡 2

であるから

𝐼 ( 𝜃 ) = 2 ∫ 𝑓 ( 2 𝑡 1 − 𝑡 2 , 1 + 𝑡 2 1 − 𝑡 2 , 2 𝑡 1 + 𝑡 2 ) d 𝑡 1 + 𝑡 2

という有理関数の積分に帰着できる。
